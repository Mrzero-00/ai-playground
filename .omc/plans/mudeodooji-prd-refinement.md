# 묻어두지 PRD 정비 계획

## 목적

기존 콘셉트 기획서를 제품·디자인·개발·QA와 Codex가 같은 결과로 구현할 수 있는 실행 기준으로 바꾼다.

## 산출물

- `묻어두지/docs/PRD.md`: 제품 범위, 정책, 요구사항 ID, 성공 지표와 출시 게이트
- `묻어두지/docs/architecture.md`: 상태 머신, 데이터·권한 경계와 서버 트랜잭션
- `묻어두지/docs/IMPLEMENTATION_PLAN.md`: 의존성 있는 작업 패킷과 검증 전략
- `묻어두지/AGENTS.md`: 후속 Codex 작업의 문서 우선순위와 불변 규칙

제품 행동의 최종 기준은 PRD이며 이 파일은 작업 과정만 기록한다.

## 핵심 결정

- 대한민국 만 18세 이상 비공개 파일럿으로 제한한다.
- V1은 2~8명, 한 가지 놀이, 텍스트와 선택 사진 한 장만 지원한다.
- 날짜·장소·정족수는 발행 후 잠그고 서버가 최종 판정한다.
- 정족수 충족과 실제 공개 사이를 서버 권위의 10초 카운트다운으로 분리한다.
- 정상 공개 콘텐츠는 30일, 열지 못한 봉인 콘텐츠는 공개 예정 시각 후 90일 보존한다.
- 외부 사용자의 첫 업로드 전에 삭제·신고·차단·콘텐츠 검사와 법률·하위 처리자 검토를 통과한다.
- Places와 미디어 처리는 Supabase Edge 제한을 넘지 않도록 고정 egress·컨테이너 런타임의 Cloud Run 작업 계층으로 분리한다.
- 최소 30일 대기를 실제 관찰할 수 있도록 기준 일정을 16주로 잡는다.

- [x] 문서 링크와 표현상 충돌 검사를 통과한다.

## 미검증 경계

- 실제 iOS·Android 카메라와 GPS
- 실제 푸시 전달
- Supabase 다중 사용자·RLS·공개 트랜잭션
- 위치기반서비스 신고 범위와 외부 처리자 계약의 전문가 승인

위 항목은 문서 완료가 아니라 V1 구현 및 외부 파일럿 게이트에서 검증한다.
