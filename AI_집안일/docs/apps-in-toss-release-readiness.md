# 집토리 앱인토스 출시 준비 체크리스트

기준일: 2026-07-28

## 현재 결론

웹 빌드, 자동 테스트와 `.ait` 생성은 가능하다. 앱인토스 익명 사용자 식별, 외부 API CORS, 동기화 충돌 방지, 데이터 삭제 코드도 준비됐다.

그러나 운영 Supabase가 연결되지 않아 Vercel `/api/state`가 500을 반환했고, 최종 `appName`·아이콘·정책 URL·실기기 검증이 확정되지 않았다. 따라서 현재 상태는 **코드 후보 준비 / 출시 검수 요청 불가**다.

## 운영 환경변수

서버 전용:

- `SUPABASE_URL`
- `SUPABASE_SECRET_KEY`
- `SESSION_SECRET` — 32자 이상
- `ALLOWED_ORIGINS` — 쉼표로 구분한 정확한 Origin

빌드 시 클라이언트:

- `VITE_API_BASE_URL`
- `VITE_ENABLE_DEMO_DATA=false`
- `VITE_TERMS_URL`
- `VITE_PRIVACY_URL`
- `VITE_SUPPORT_URL`
- `VITE_TOSS_SHOPPING_URL_TEMPLATE` — 승인 전 빈 값

앱인토스 Origin:

- `https://<appName>.apps.tossmini.com`
- `https://<appName>.private-apps.tossmini.com`

## 출시 후보 검증 명령

```bash
pnpm verify
```

성공 후 다음을 별도로 확인한다.

1. `https://<vercel-domain>/api/session` JSON 200
2. 새 사용자 `/api/state` JSON 200
3. 초대 코드로 두 사용자가 같은 집 조회
4. 동시에 수정했을 때 한 사용자에게 409 충돌 안내
5. 탈퇴 후 개인 기록 삭제와 공유 집 유지
6. 앱인토스 안에서 같은 사용자가 재진입해 동일 데이터 조회
7. 정책 링크와 승인된 외부 링크 정상 이동

## 출시 판정

아래 중 하나라도 남아 있으면 출시 가능으로 보고하지 않는다.

- 운영 DB/API 500 오류
- 최종 콘솔 정보 불일치
- 정책·문의 URL 미설정
- 데이터 삭제 통합 테스트 미완료
- 실제 토스 샌드박스 뒤로가기·딥링크 미검증
- 승인되지 않은 토스쇼핑 또는 광고 링크
