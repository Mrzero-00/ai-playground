# betman-dashboard

> 승부예측 프로그램의 추천 조합·티켓 성적·과정 회고(4분면)와 지정 리그(5대 리그) 팀별 xG·선수·포메이션 기록을 보여 주는 정적 대시보드 (Vercel 배포)

- 데이터: `../승부예측 프로그램/scripts/dashboard_data.py` 가 `data/*.json` 을 생성한다(08시 정기 작업·블록 점검 뒤 갱신, 커밋에 포함).
- 사이트: 빌드 없는 정적 SPA(`index.html` + `app.js` + `styles.css`), Chart.js(cdnjs). Vercel 은 이 폴더를 루트로 정적 배포한다.
- 화면: 홈(가상 추천 모드 성적·오늘 추천) · 추천 조합 · 티켓 · 과정 회고(실력/운/분산/오판) · 리그 → 팀(xG 흐름·선수 기여·포메이션·최근 경기·상대 포메이션별).
