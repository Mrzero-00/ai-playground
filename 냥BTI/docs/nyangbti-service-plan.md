# 냥BTI 서비스 기획서

> 문서 상태: 복원 작업판(reconstructed working edition)
> 작성 기준: 2026-08-19

## 문서 출처와 주의사항

이 문서는 이전 ChatGPT 대화에서 확인할 수 있었던 기획 사실과 현재 로컬 MVP 범위를 바탕으로 다시 정리한 작업용 문서다. 이전 대화에서 생성됐던 원본 첨부 파일 `nyangbti-service-plan.md`의 본문과 16개 캐릭터 이미지 원본은 현재 작업 환경에서 열 수 없었다. 따라서 이 파일은 원본의 축약본이나 완전한 사본이 아니며, 개발을 이어가기 위한 복원판이다.

냥BTI는 사람의 MBTI 검사를 고양이에게 적용한 검사가 아니다. 고양이의 평소 행동을 여섯 개 연속형 Trait으로 정리한 뒤, 결과를 쉽게 이해하고 공유할 수 있도록 익숙한 4글자 형식을 차용한 엔터테인먼트·생활 관찰 서비스다. 본 결과는 성격 검사, 수의학적 검사, 질병 진단 또는 치료 조언으로 사용할 수 없다.

## 1. 서비스 한 줄 정의

집사가 관찰한 30개 생활 행동을 바탕으로 고양이의 성향을 6개 연속형 점수와 16개 냥BTI 캐릭터로 보여주고, 집사 또는 다른 고양이와의 생활 궁합과 맞춤 생활 팁을 제공하는 모바일 우선 서비스다.

## 2. 해결하려는 문제

- 집사는 고양이의 행동을 보면서도 그것이 평소 성향인지, 특정 상황의 반응인지 구분하기 어렵다.
- 기존의 가벼운 성격 테스트는 공유하기는 쉽지만 실제 생활에 적용할 안내가 부족하다.
- 반대로 전문 행동 자료는 처음 접하는 사용자가 이해하기 어렵고 진입 장벽이 높다.
- 고양이의 조용함, 독립성, 민감함 같은 특성을 문제 행동이나 질병으로 단정하면 안 된다.

냥BTI는 `재미있는 유형 결과 → 연속형 행동 성향 → 집사·고양이 생활 궁합 → 생활 관리 팁` 순서로 진입 장벽과 실용성 사이를 연결한다.

## 3. 핵심 원칙

1. 행동 문항을 주 판정 근거로 사용한다.
2. 생년월일은 연령 맥락, 품종·성별·중성화 여부는 프로필 참고 정보로만 다룬다.
3. 외형이나 품종만으로 성격을 단정하지 않는다.
4. 내부에는 `0~100` 범위의 6개 연속형 Trait을 유지한다.
5. 고양이 MBTI 유형은 이해와 공유를 위한 표현 계층이며, 실제 설명과 추천에는 6개 Trait을 함께 사용한다.
6. 최근의 갑작스러운 행동 변화는 성향 점수와 분리한다.
7. 의료적 단정 대신 관찰과 필요 시 수의사 상담을 안내한다.

## 4. 대상 사용자

- 반려묘의 평소 행동을 더 잘 이해하고 싶은 집사
- 새로 고양이를 입양해 관계와 환경을 조정하는 사용자
- 가족이나 친구와 재미있는 결과를 공유하고 싶은 사용자
- 여러 고양이의 서로 다른 생활 선호를 기록하고 싶은 사용자

한 번의 검사에서는 한 마리의 고양이를 평가해요. 여러 고양이 프로필과 고양이끼리의 생활 궁합은 구현되어 있지만 선택 기능이며, 각 고양이의 검사를 따로 완료해야 해요.

## 5. MVP 사용자 흐름

```text
시작
  ↓
서비스 성격 및 비진단 고지
  ↓
고양이 프로필 입력
  - 이름
  - 생년월일
  - 품종
  - 성별
  - 중성화 여부
  - 집사 MBTI 또는 "잘 모르겠어요"
  ↓
30개 상황형 행동 문항
  ↓
6개 Trait 정규화
  ↓
4개 냥BTI 축과 16개 유형 계산
  ↓
결과 페이지
  - 캐릭터 Hero
  - 냥BTI 코드·유형명·설명
  - 4축 수준과 6개 Trait 시각화
  - 성향·주의·관찰·관리 콘텐츠
  - 집사와의 엔터테인먼트성 궁합
  - 고양이끼리 생활 궁합 진입
  - 공유 전용 화면 진입
  ↓
재검사 또는 처음으로
```

설문 진행 상태와 프로필은 Zustand persist로 로컬에 보존해 WebView 이동이나 일시적인 중단 뒤에도 이어서 답할 수 있게 한다.

## 6. 내부 행동 모델

| Trait | 서비스에서 보는 행동 범위 |
|---|---|
| `sociability` | 사람에게 접근하고 접촉·교감을 주고받는 경향 |
| `boldness` | 낯선 물건·공간·상황에 접근하고 탐색하는 경향 |
| `activity` | 이동, 점프, 높은 공간 이용, 자발적 활동의 정도 |
| `playfulness` | 장난감·추적·매복·사냥형 놀이에 참여하는 경향 |
| `adaptability` | 환경, 자원, 사람의 변화 뒤 일상으로 적응하는 정도 |
| `sensitivity` | 소리, 냄새, 움직임, 접촉과 스트레스 상황에 민감하게 반응하는 정도 |

같은 냥BTI 유형이라도 여섯 점수의 강도가 다를 수 있다. 따라서 결과의 주의사항과 관리 팁은 유형명 하나가 아니라 Trait의 높고 낮음과 조합을 참고해 보여준다.

### 4개 표현 축

| 축 | 냥BTI에서의 의미 |
|---|---|
| `E / I` | Extrovert / Introvert — 사람·고양이에 대한 사회적 접근성 |
| `N / S` | Novelty / Stability — 새로운 환경 탐색과 익숙한 환경 선호 |
| `F / T` | Friendly / Tough — 친화적 상호작용과 독립적·강한 자기주장 |
| `P / J` | Playful / Judicious — 즉흥적·놀이 지향과 신중·안정 지향 |

이전 원본 스코어링 첨부의 세부 가중치와 정규화·4축 변환 공식은 복구되지 않았다. 현재 코드의 수치와 공식은 개발 가능한 MVP를 위한 재구성 모델이며, 검증된 수의행동학 공식으로 소개해서는 안 된다. 실제 출시 전에는 가상 Persona 분포 테스트, 극단 응답 테스트, 결측 응답 테스트와 전문가 검토가 필요하다.

## 7. 16개 냥BTI 유형

아래 코드와 유형명은 이전 대화에서 확인된 명칭을 그대로 유지한다.

| 코드 | 유형명 |
|---|---|
| ENFP | 호기심 많은 인싸 탐험가 |
| ENFJ | 다정한 고양이 반장 |
| ENTP | 장난꾸러기 발명가 |
| ENTJ | 당당한 냥대장 |
| ESFP | 신나는 분위기 메이커 |
| ESFJ | 사랑받는 애교쟁이 |
| ESTP | 행동파 사냥꾼 |
| ESTJ | 우리집 냥대장 |
| INFP | 감성적인 몽상가 |
| INFJ | 조용한 마음 읽기 장인 |
| INTP | 호기심 많은 관찰자 |
| INTJ | 독립적인 전략가 |
| ISFP | 느긋한 힐링냥 |
| ISFJ | 따뜻한 집순이/집돌이 |
| ISTP | 독립적인 사냥꾼 |
| ISTJ | 신중한 안전 지킴이 |

유형 콘텐츠는 단정형 문장보다 `~하는 편이에요`, `~할 가능성이 있어요`처럼 관찰 가능성과 개체 차이를 남기는 언어를 사용한다.

## 8. 결과 페이지 콘텐츠 구조

### 8.1 Character Hero

- 캐릭터 일러스트는 고양이 캐릭터만 담는다.
- 코드, 유형명, 설명, 점수와 높음·중간·낮음 표시는 HTML로 렌더링한다.
- 이전 대화에서 16개의 `1024×1024 PNG`가 생성됐다는 기록은 있으나, 해당 원본 자산은 현재 환경에서 복구되지 않았다.
- 실제 캐릭터가 준비되기 전에는 텍스트가 들어간 임시 이미지를 결과 Hero로 사용하지 않는다.

### 8.2 핵심 결과

- 고양이 이름
- 냥BTI 코드와 유형명
- 한 줄 캐치프레이즈
- 친근한 유형 설명
- `E/I · N/S · F/T · P/J` 각 축의 선택 글자와 수준
- 여섯 Trait의 막대 또는 레이더형 시각화

### 8.3 생활 콘텐츠

- `이런 성향이에요`: 높은 점수와 점수 조합을 생활 언어로 설명
- `조심할 부분`: 탈출, 자원 경쟁, 과자극, 무료함처럼 환경에서 예방할 수 있는 상황
- `관찰 신호`: 평소 기준선과 달라졌는지 확인할 구체적 행동
- `추천 관리`: 놀이, 환경, 생활, 관계 네 범주
- `고양이 궁합`: 여러 고양이의 연속 성향을 비교한 생활 리듬 유사도와 개별·공통 팁
- `공유`: 캐릭터, 코드, 유형명, 여섯 성향 점수를 공식 앱인토스 링크로 공유

## 9. 집사 MBTI 궁합

집사의 사람 MBTI는 고양이의 유형 코드와 고정 점수표로 단순 결합하지 않는다. 다음 구조로 처리한다.

```text
집사 MBTI
  ↓
집사의 Interaction Profile
  - interaction
  - stimulation
  - routine
  - independence
  - adaptability
  ↓
고양이의 실제 6 Trait
  ↓
엔터테인먼트성 궁합 점수와 설명
```

결과에는 다음을 제공한다.

- 궁합 점수
- 가장 가까운 생활 방식
- 맞춰주면 좋은 점
- 함께 지내는 팁

집사 MBTI를 모르는 사용자는 검사 흐름을 막지 않고 `잘 모르겠어요`를 선택할 수 있어야 한다. 궁합 영역에는 다음 취지의 고지를 항상 노출한다.

> 이 궁합은 고양이의 관찰된 행동 성향과 집사 MBTI를 재미있게 연결한 콘텐츠이며, 과학적 궁합 검사나 수의학적 진단이 아닙니다.

## 10. 안전한 표현

앱은 행동 성향과 생활 리듬을 재미로 비교하며 원인을 추정하거나 질환, 친밀도, 서열, 합사 성공 여부를 판정하지 않아요. 결과와 궁합 화면에는 비진단·비합사판정 고지를 제공하고, 행동 변화가 지속되거나 걱정되는 경우 수의사 또는 고양이 행동 전문가와 상의하도록 안내해요.

## 11. App in Toss 방향

MVP는 모바일 우선 Next.js App Router, TypeScript, SCSS, Zustand 구조를 사용한다. App in Toss 연동 전까지 브라우저에서도 실행 가능한 웹 앱으로 유지한다.

필수 고려사항은 다음과 같다.

- 상·하단 safe-area를 고려한 레이아웃
- 작은 모바일 화면에서도 한 손으로 진행할 수 있는 문항 UI
- WebView 내비게이션과 기기 뒤로가기 처리
- 설문 중 이탈 후 복귀를 위한 로컬 persist
- 결과 공유 실패 시 복사 등 안전한 대체 동작
- 실제 SDK가 없는 환경에서도 동작하는 adapter 경계
- 캐릭터 이미지 최적화와 지연 로딩
- 접근 가능한 대비, 터치 영역, 대체 텍스트

개발 및 출시 전에는 공식 운영 자료를 최신 상태로 다시 확인한다.

## 12. Toss Ads BM

초기 BM은 App in Toss가 허용하는 Toss Ads를 이용하는 방향이다. 실제 광고 SDK는 아직 직접 결합하지 않고 `AdSlot`과 광고 adapter를 통해 분리한다.

### 광고 배치 원칙

- 사용자가 결과라는 가치를 받은 뒤 자연스러운 전환 지점에 둔다.
- 시작 화면, 프로필 작성, 문항 응답 중간에는 흐름을 끊는 광고를 두지 않는다.
- 광고 때문에 뒤로가기나 결과 확인이 막히는 구조를 만들지 않는다.
- 개발 환경에서는 placeholder 또는 noop adapter를 사용한다.
- 실제 연동 전 공식 지원 형식, 테스트 ID, 노출·수명주기 규칙을 재확인한다.
- 광고 표기와 콘텐츠를 명확히 구분하고 오클릭을 유도하지 않는다.

광고 외 확장 BM은 MVP 검증 후 검토한다. 예시는 재검사 추이, 상세 케어 리포트, 제휴형 생활용품 추천이지만, 의료 효능을 암시하거나 결과를 이용해 불안을 과장해서는 안 된다.

## 13. 공유·리텐션 방향

- 캐릭터와 유형명을 먼저 확인하는 공유 전용 화면
- 앱인토스 공식 공유 링크로 공유받은 고양이와 내 고양이의 궁합 연결
- 일정 기간 뒤 재검사하고 이전 결과와 비교하는 기능
- 여러 고양이 프로필 저장과 다묘 관계 팁

공유 화면에도 `고양이 행동 성향을 재미있게 표현한 결과`라는 취지를 유지해요.

## 14. MVP 완료 기준

- 시작 → 프로필 → 30문항 → 결과 전체 흐름이 모바일에서 동작한다.
- 새로고침 또는 WebView 복귀 후 설문을 이어갈 수 있다.
- 여섯 Trait과 4축, 16개 유형이 결정론적으로 계산된다.
- 모든 유형에 기본 설명, 주의, 관찰, 네 범주의 관리 팁이 있다.
- 집사 MBTI 미입력과 16개 입력 모두 안전하게 처리된다.
- 결과와 궁합이 진단 또는 합사 성공 판단으로 보이지 않게 안내한다.
- 광고와 WebView 기능이 adapter 없이도 앱을 깨뜨리지 않는다.
- lint, typecheck, test, production build를 통과한다.

## 15. 출시 전 검증 과제

1. 가상 고양이 Persona 20~30개로 유형 쏠림과 모순 결과를 점검한다.
