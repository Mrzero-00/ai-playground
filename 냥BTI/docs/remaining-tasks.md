# 냥BTI 잔여 작업

최종 정리일: **2026-08-31 (Asia/Seoul)**

현재 로컬 웹 MVP에서 바로 해결 가능한 개발·테스트 작업은 완료했다. 아래는 사용자 계정, 외부 승인, 실제 기기 또는 전문 검토가 있어야 진행할 수 있는 작업이다.

## 1. 사용자 계정·승인이 필요한 필수 작업

- [x] App in Toss 콘솔의 기존 미니앱과 실제 값을 확인한다: 워크스페이스 `상일의플레이그라운드`, 표시명 `고양이 MBTI`, `appName` `cat-mbti-00`.
- [x] App in Toss Web Framework 3.1.1, 콘솔 `appName`, 브랜드 색, 네이티브 내비게이션, Safe Area를 연결하고 `.ait` 번들을 만든다.
- [x] `cat-mbti-00.ait`를 콘솔 첫 버전 `20260831-1`로 등록한다.
- [ ] 사업자·정산 정보를 등록하고 검토를 받은 뒤 광고 그룹을 생성해 테스트/운영 광고 ID를 발급받는다.
- [ ] 토스 워크스페이스 멤버 계정과 실제 iOS·Android 기기로 QR 테스트를 1회 이상 완료한다.
- [ ] 콘솔에서 비게임 미니앱 검토를 요청하고, 승인 후 사용자가 직접 `출시하기`를 실행한다.

## 2. App in Toss 실환경에서 마무리할 개발·QA

- [x] 콘솔 `appName`과 최신 공식 문서를 기준으로 SDK 패키지와 설정을 확정한다.
- [x] 토스 내비게이션 바, 첫 화면 종료, 내부 뒤로가기와 시스템 뒤로가기를 SDK adapter로 연결한다.
- [x] 현재 SDK의 `SafeArea` API를 CSS 변수에 연결한다.
- [ ] iOS 스와이프, Android 시스템 뒤로가기, 노치·Dynamic Island·홈 인디케이터를 실제 기기에서 확인한다.
- [ ] 발급받은 공식 광고 ID로 광고 adapter를 구현하고 미지원 버전에서 빈 영역이 남지 않는지 확인한다.
- [x] `.ait` 압축 해제 용량이 100MB 이하인지 측정한다. 2026-08-31 빌드 기준 약 14.3MB다.
- [ ] QR·라이브 Origin에서 CORS와 공유 동작을 재검증한다.

자세한 실행 체크리스트는 [`app-in-toss-checklist.md`](app-in-toss-checklist.md)에 있다. SDK 버전과 정책은 연동 직전 다시 확인한다.

## 3. 외부 전문 검토·운영 준비

- [ ] 수의행동 전문가가 30문항, 가중치, Behavior Check 문구와 결과 관리 팁을 검토한다.
- [ ] 충분한 실제 응답 데이터를 모아 Trait 분포, 4축 경계, 궁합 점수 분포를 보정한다.
- [ ] 개인정보 처리방침, 이용약관, 고객 문의 채널과 운영 책임자를 확정한다.
- [ ] 출시 후 오류·성능·사용자 이탈을 확인할 모니터링과 장애 대응 절차를 준비한다.
