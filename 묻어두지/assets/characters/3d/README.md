# 두지 3D 제작 자료

아직 실제 3D 모델 또는 애니메이션은 생성되지 않았다.

`source/dooji-b-upload.jpg`는 기존 B 캐릭터 원화를 원본 손상 없이 업로드 준비용으로 축소·JPEG 인코딩한 사본이다. 외부 전송은 자동 안전 검토에서 거절되었으며, 해당 파일을 fal.ai에 보내는 명시적 사용자 승인을 기다린다. 생성 요청이나 유료 모델 실행은 하지 않았다.

제작할 모션은 캡슐 묻기, 캡슐 꺼내기, 잠금에 막혀 실망하기다. 모델·관절·소품이 준비된 뒤 실제 애니메이션으로 제작한다. 자세한 연출, 서버 조건, 비용 및 검증 기준은 `../../../docs/AR_CHARACTER_MOTIONS.md`에 기록했다.
