# 캡슐 SVG 컴포넌트

플랫 벡터 스티커 스타일 타임캡슐. viewBox 240×240, 외곽선 #111 5px(240 기준), 몸통 #5FDCFF, 음영 #00C2F5, 띠 #FFE07A.

- `capsule-closed.svg` — 닫힘 (홈·카드·아이콘)
- `capsule-open.svg` — 열림 (열림 화면·넣기 화면)
- `capsule-buried.svg` — 묻힘 (기다리기 화면)

앱에서는 `react-native-svg`로 같은 패스를 옮겨 쓴다. 디자인 캔버스의 `Capsule.dc.html`과 동일한 소스다.
