# 아이폰 기능 검증 체크리스트

실행 전 `npm run server`, `npm start`를 켜고 `npm run ios`로 개발 앱을 설치한다. 같은 Wi-Fi, 자동 날짜/시간, 정확한 위치, 카메라 권한이 필요하다. 녹음 시에는 마이크 권한도 요청한다. 음성·영상 모듈을 추가했으므로 기존 개발 앱은 재빌드한다. 앱을 사용하며 설정해야 하는 기기 신뢰/개발자 모드/서명은 사용자가 직접 완료한다.

## 1. 첫 번째 성공 경로

1. `LAB → 연결 확인`에서 서버 응답을 확인한다.
2. `실제 위치 확인`에서 오차 25m 이하인지 확인한다. 안 되면 하늘이 보이는 곳으로 이동한다.
3. 새 캡슐을 만들고 테스트 편지와 테스트 사진 1장을 선택한다.
4. 개봉 시간을 **15초** 또는 **1분**으로 정한다.
5. `현재 장소에서 AR로 묻기`를 누른다.
6. 밝은 곳에서 휴대폰을 천천히 움직여 초록색 바닥이 나타나는지 확인한다.
7. 바닥을 누르고 캡슐이 나타나면 `여기에 봉인하기`를 누른다.
8. 봉인 후 편지/사진 미리보기가 사라지고 이름·장소·개봉일만 남는지 확인한다.
9. 시간이 지난 뒤 같은 장소에서 `AR로 꺼내기`를 누른다.
10. 바닥을 다시 선택하고 `캡슐 열기`를 눌러 원본 편지/사진이 일치하는지 확인한다.

## 2. 차단·복구 경로

| 시나리오 | 기대 결과 |
| --- | --- |
| 개봉 시간 전 시도 | 남은 시간 안내, 내용 미전달 |
| 묻은 위치에서 50m보다 멀리 이동 | 거리 안내, 개봉 거부 |
| 위치 권한 거부/정확한 위치 끄기 | 안내 또는 오차 거부, 자동 우회 없음 |
| 카메라 권한 거부 | 설정 안내, 봉인/개봉 버튼 실행 안 됨 |
| 평면 인식 전/추적 상실 | AR 액션 비활성화 |
| 서버 끈 상태로 개봉 | 연결 실패, 내용 미전달 |
| 봉인 요청 직후 Wi-Fi 끊기 | 작성 내용 숨김 유지; 재연결 후 상태 확인으로 캡슐 1개만 남음 |
| 개봉 버튼 직후 앱을 백그라운드로 보내기 | 늦은 응답으로 내용 화면이 다시 열리지 않음 |
| 개봉 화면에서 앱을 백그라운드로 보내기 | 돌아오면 내용 대신 캡슐 상세 화면 |
| 앱/서버 재시작 | 내 캡슐 메타데이터 유지 |
| 웹에서 AR 봉인 시도 | 실기기 개발 빌드 안내, 실제 봉인 없음 |

위치 거리 판정은 센서 측정값 기준이다. 반경 가장자리만으로 성공/실패를 판단하지 말고, 충분히 가까운 지점과 충분히 먼 지점에서 각각 확인한다. 도로·출입 금지 구역으로 이동하며 테스트하지 않는다.

## 3. 음성·영상

1. 새 캡슐에 짧은 테스트 목소리를 녹음하고 중지 후 미리 듣는다. 녹음 중에는 봉인 버튼이 비활성화되어야 한다.
2. 60초에 자동으로 녹음이 끝나고 첨부되는지, 취소·화면 이탈·백그라운드 전환 시 마이크가 꺼지는지 확인한다.
3. 마이크 권한 거부 시 안내가 나오고 파일 선택은 계속 가능한지 확인한다.
4. M4A·MP3·WAV를 각각 선택해 미리 듣고, 다른 파일로 교체/빼기가 되는지 확인한다.
5. 짧은 MP4와 MOV를 선택해 영상·소리를 확인한다. 무음 영상도 정상적으로 담을 수 있어야 한다.
6. 음성만, 영상만, 사진·편지·음성·영상 모두 담은 캡슐을 각각 15초로 봉인한다.
7. 봉인 전 재생 중 AR로 이동하면 재생이 멈추고, 봉인 후 파일명·재생 버튼·미리보기가 사라져야 한다.
8. 개봉 조건을 통과한 뒤 음성·영상이 원본대로 재생되는지 확인한다. 개봉 화면 이탈/백그라운드 전환 시 재생이 멈춰야 한다.
9. 음성 10MB 초과/영상 25MB 초과 파일, 지원하지 않는 확장자는 선택 후 명확한 오류가 나오는지 확인한다.
10. 큰 첨부 파일 업로드 중 연결을 끊었다가 복구해도 내용 숨김이 유지되고 캡슐이 중복 생성되지 않아야 한다.

기기 모델·OS 버전과 테스트 파일의 형식/코덱/크기를 함께 기록한다. 브라우저 파일 선택·재생 성공은 native 녹음/재생 검증을 대신하지 않는다.

## 4. 기록할 항목

- 기기 모델 / iOS 버전 / 앱 빌드
- 실외·실내 / 조명 / 바닥 재질
- 측정 위치 오차 / 서버가 표시한 거리
- 평면 인식 성공 여부와 걸린 시간
- 사진/편지/음성/영상 내용 일치 여부, 녹음과 재생 결과
- 차단/복구 케이스의 성공 여부

AR 배치는 현재 세션의 바닥을 사용한다. 묻었던 바닥의 정확한 위치가 다시 인식되는지 검사하는 테스트는 현재 범위가 아니다.
