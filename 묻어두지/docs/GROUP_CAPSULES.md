# 개인·공동 캡슐 MVP 규칙

## 사용자 흐름

1. **개인**: ‘나 혼자’를 선택해 사진·편지·음성·영상을 담고, 현재 장소의 카메라 AR에서 바닥을 선택해 봉인한다. 약속한 시각 이후 같은 장소에서 본인 기기로 꺼낸다.
2. **공동 모임**: 만든 사람이 이름·모임 이름·본인 포함 전체 인원 N(2~20명)을 정한다. 친구들은 각자의 앱에서 이름과 초대 코드를 입력한다. 같은 기기 세션으로 여러 이름을 입력해도 여러 명으로 세지 않는다.
3. **공동 봉인**: N명이 모두 등록되면 만든 사람이 내용을 담아 현장에서 봉인한다. 묻을 때 전원이 현장에 있을 필요는 없고, 꺼낼 때 전원이 필요하다. 한 모임은 한 캡슐에 연결되며 봉인 후 명단과 N은 고정된다.
4. **공동 개봉**: 약속한 시간이 지난 뒤 전원이 장소로 돌아와 각자 ‘함께 열기 참여’를 누른다. 이름별 참석 상태와 N명 중 몇 명이 도착했는지를 보여준다. 전원의 참석이 유효할 때 각자가 카메라 AR에서 캡슐을 꺼내고 같은 내용을 볼 수 있다.

사진 1장(4MB), 편지(10,000자), 음성 1개(10MB, 직접 녹음 최대 60초), 영상 1개(25MB)를 함께 담을 수 있다. MVP에서는 모임을 만든 사람만 작성하며 참여자별 업로드/공동 편집은 제공하지 않는다.

## 서버의 개봉 조건

- 개인 캡슐 소유자 또는 공동 캡슐의 확정된 참여자인지 확인한다.
- 서버 시각이 개봉 시각에 도달했어야 한다. 기본 선택은 30일이며, 검증용 15초·1분·5분·하루가 남아 있다. 운영용 최소 1개월 정책을 강제하는 버전은 아니다.
- 각 참여자의 신고 위치가 캡슐 중심 반경 **50m** 안이어야 한다. 위치 오차 **25m 이하**, 측정 시각 **30초 이내**, 미래 시각 허용 오차 **5초** 기준을 사용한다. 알려진 mock 위치는 거부한다.
- 공동 참석은 참여 버튼 이후에만 시작한다. 서버는 기기 세션과 캡슐에 묶인 참석 토큰, 증가 순번, 최근 위치를 사용한다. 약 5초마다 새 위치를 측정해 갱신한다. 위치 측정 및 통신 시간 때문에 실제 간격은 길어질 수 있다.
- 참석 갱신은 서버가 받은 시각부터 **20초 미만**만 유효하다. 정확히 20초가 되면 참석 인원에서 제외한다. 오래된 순번이나 다른 기기의 참석 토큰으로 갱신할 수 없다.
- 화면 이탈·앱 비활성화 시 종료 요청을 보낸다. 연결이 끊겨 요청이 전달되지 않으면 남은 유효 시간 동안 표시될 수 있다. 새 요청에서 먼 위치/잘못된 위치가 확인되면 직전 참석도 무효화한다.
- 개봉 API는 매번 모든 조건을 다시 검사한 뒤에만 내용을 읽는다. 한 번 열었다고 영구 해제되지 않는다. 개봉 화면에서도 참석 갱신을 계속하며 조건 이탈/확인 실패가 전달되면 내용을 닫는다. 이미 내려받거나 촬영한 내용의 복제를 막는 DRM 기능은 아니다.

## 저장·개인정보와 한계

- 모임·명단·봉인 내용은 SQLite에 저장한다. 기존 개인 캡슐 및 재전송 식별자는 유지한다.
- 참석 GPS·토큰은 서버 메모리에만 둔다. 서버 재시작 시 참석이 모두 초기화된다. 상대에게는 이름·참석 여부만 전달하고 정확한 현재 좌표와 참석 토큰은 공개하지 않는다.
- 캡슐 장소 좌표는 참여자에게 제공하지만 편지·첨부 본문·파일명은 개봉 조건을 통과하기 전에는 전달하지 않는다.
- 현재 인증은 사람의 신원을 확인한 계정이 아니라 **각 설치의 기기 세션**이다. 한 사람이 여러 세션을 만드는 것, GPS/API 위조, 실제 사람 수를 암호학적으로 보장하지 않는다.
- 기기 분실이나 세션 초기화 시 공동 명단을 대체/복구하는 기능이 없다. 누구 하나 접근 권한을 잃으면 전원 개봉 조건을 충족할 수 없으므로 테스트 자료만 사용한다. 정식 서비스에는 계정 복구와 모든 참여자가 합의하는 예외 정책이 필요하다.
- ‘같은 장소’는 GPS 반경 50m이며 참여자끼리 정확히 같은 한 점에 있다는 뜻은 아니다. AR 오브젝트는 당시 인식한 평면에 재배치한다. 과거의 바닥 좌표/방향을 복원하거나 클라우드 앵커를 공유하지 않는다.
- 웹은 모임 생성·참여·메타데이터 화면 검사용이다. AR 봉인/개봉 및 현장 참석은 네이티브 개발 빌드에서만 시작한다. 실제 AR·GPS·녹음·재생·다중 아이폰 참석은 아직 현장 검증 전이다.
