# 묻어두지 — 가볍게 묻고, 다시 만날 핑계

작성일: 2026-09-17

## 서비스의 무게를 조금 덜기

묻어두지는 인생의 중요한 순간만 보관하는 기록관이 아니다. 오늘 한 아무 말, 웃긴 사진, 별것 아닌 다짐을 묻어두고 나중에 다시 만날 핑계를 만드는 서비스다. 친구·연인·가족이 주요 관계이고, 혼자 미래의 나에게 남겨도 된다.

기다리고 직접 찾아가야 하는 불편함 자체가 작은 놀이가 된다. 다만 위치 오류, 일정 불일치, 관계 변화까지 장난스럽게 취급하지 않는다. 캐릭터는 대기를 재미있게 만들고, 시스템은 조건과 제한을 정확하게 설명한다.

## 이번 코드에 적용한 것

기준 소스는 원격 `codex/mudeoduji-ar-prototype`의 2026-09-15 커밋 `6944ae7`이다. 작업 브랜치는 `codex/mudeoduji-soft-ui`이며 원본 작업 폴더와 분리했다.

- 기본 화면은 지도다. 지도 오른쪽에 캡슐 묻기와 현재 위치 버튼을 두고, 아래에는 내 캡슐 목록 서랍을 둔다. 서랍은 손잡이 탭 또는 드래그로 펼친다. 지도 핀과 목록 모두 캡슐 상세로 연결된다.
- 기본 시점은 55도 기울기와 -28도 방향의 쿼터뷰다. 가까운 길은 넓고 먼 길은 작게 보이며, 상단의 옅은 안개로 거리감을 준다. 캡슐/제목/카운트다운은 정면으로 선 채 실제 위치를 따라간다. 오른쪽 `2D` 버튼은 기울기·방향을 모두 0도로, `3D`는 원래 쿼터뷰로 바꾸며 지도 이동/확대와는 별개다. 원근 표현이며 건물 높이/지형 3D 모델 또는 포켓몬고 그래픽을 복제한 것은 아니다.
- 지도에는 하늘색 캡슐이 바닥의 작은 타원 그림자 위에서 2.8초 주기로 8px 정도 떠오른다. 말풍선에 제목과 `일·시간·분·초`를 항상 함께 표시하고, 숫자는 서버 보정 시각을 받아 매초 갱신한다. 0초 이후는 버터색 ‘열어볼 시간!’, 열어본 캡슐은 차분한 녹색으로 구분한다. 실제 개봉 조건은 그대로다.
- 캡슐의 바닥 표시가 저장 좌표에 붙어 있고 그림만 움직인다. 시간 갱신 때문에 지도/마커를 재생성하거나 위치를 옮기지 않는다. 지도 뒤의 패널/백그라운드에서는 모션을 쉬고, 운영체제의 동작 줄이기 설정을 따른다. 웹 타이머를 매초 음성으로 읽지는 않으며 마커에 초점을 맞추면 제목·남은 시간을 확인할 수 있다.
- 하늘색 머리말, 흰 종이, 얇은 구분선, 버터색 메모. 핵심 버튼은 짙은 청록색으로 대비를 확보한다.
- 전체 / 기다리는 중 / 꺼낼 시간 / 열어본 약속 필터. 열어본 캡슐도 본문을 목록에 노출하지 않는다.
- 두지 캐릭터와 짧은 농담. “잘 묻었어요. 삽은 잠깐 치워둘게요.”, “이걸 내가 썼다고요?”
- 고정 하단 탭 대신 지도 상단 ‘함께’·‘설정’과 오른쪽 ‘캡슐 묻기’를 사용한다. 작성·모임·상세 화면은 지도 위의 패널로 열리고 뒤로 가면 지도와 목록 상태를 유지한다. 작성 화면의 임시 입력도 유지하며 녹음 취소·파일 정리 규칙은 기존 구현을 따른다.
- 편지·사진·음성·영상 작성, 미디어 컨트롤, 봉인 대기, 상세, 개봉, AR 안내 화면에 같은 팔레트를 사용한다.
- 작성 화면에는 하늘색 캡슐 하나를 중심에 둔다. 탭하면 2×2 내용 선택 메뉴가 나오고, 선택한 유형의 입력창만 연다. 사진/영상은 선택·미리보기, 음성은 녹음/파일 선택, 편지는 편지지 형태로 구분한다. 담은 항목만 캡슐 아래 작은 버튼으로 표시해 수정·빼기로 연결한다.
- 전용 창에서 입력·선택한 내용은 작성 중 캡슐에 즉시 반영하며, 완료/닫기는 봉인이 아니다. 창을 닫으면 재생을 종료하고 진행 중인 녹음은 취소한다. 화면 이동 중 초안은 유지되지만 앱 종료/새로고침 후 복구는 제공하지 않는다.
- 대기 시간 기본값은 30일. 15초·1분·5분·하루는 기존 기능 검증용 선택지로 유지하고 개발용임을 표시한다. 30일은 달력상 한 달과 같은 계산이 아니다.

`src/theme.ts`는 공통 색상, `src/styles.ts`는 앱 화면 스타일, `src/lib/timeline.ts`는 목록의 상태 분류, `src/lib/capsuleCountdown.ts`는 지도 카운트다운을 담당한다. `CapsuleHome`은 지도와 서랍을, `CapsuleAtlas`는 웹/네이티브 지도를 분리한다. 웹은 Leaflet에서 MapLibre GL JS로 교체했다. `src/lib/mapPresentation.ts`는 시점과 정확도 범위 좌표를 담당한다. 새 3D 에셋 없이 기존 SVG 캡슐을 재사용하며 여러 캡슐의 색상이 간섭하지 않도록 그라디언트 식별자를 분리했다.

## 바꾸지 않은 약속

1. 앱의 시간 표시가 개봉 허가를 의미하지 않는다. 서버가 소유권 또는 공동 명단·시간·최신 위치·거리·정확도를 다시 확인한다. 공동 캡슐은 전원 참석도 확인한다.
2. 반경 50m, GPS 오차 25m 이하, 최신 측정 30초 이내 조건을 유지한다.
3. 봉인 후 본문·사진·음성·영상은 목록에서 미리 볼 수 없다. 중복 생성 방지와 봉인 복구도 유지한다.
4. 한번 열어본 내용도 현재 버전에서는 해당 장소에서 다시 검사해야 볼 수 있다. ‘열어본 약속’은 원격 열람 보관함이 아니다.
5. AR은 iPhone/Android 개발 빌드 전용이다. 웹에서 AR 버튼은 미지원 안내를 보여주며 실제 봉인하지 않는다.
6. 지금 인식한 바닥 위에 캡슐을 배치하며, 과거에 놓은 정확한 한 점을 복원하지 않는다.
7. 로컬 검증 서버의 데이터는 암호화 없이 저장된다. 민감한 실제 사진·편지를 넣는 정식 서비스가 아니다.

## 공동 캡슐 MVP와 다음 단계

사용자 요청에 따라 **모임 만들기 → 초대 코드로 N명 등록 → 만든 사람이 내용 넣기·현장 AR 봉인 → 기다리기 → 전원이 약속 장소에서 참석 확인 → 각자 AR로 꺼내기**를 구현했다. 공동 캡슐은 2~20명이며 봉인 후 명단은 고정된다. 지도의 ‘내 캡슐’ 서랍에는 개인 캡슐과 내가 참여한 공동 캡슐을 함께 표시한다.

현재는 기기 세션 기반이며 가입 계정, 친구 목록, 사람 본인 확인, 참여자별 공동 작성, 알림은 미구현이다. 전원의 최근 위치 신고를 서버에서 검사하지만 실제 아이폰 여러 대로 현장 테스트한 결과는 아직 없다. 세부 기준은 [공동 캡슐 규칙](GROUP_CAPSULES.md)을 따른다. 다음 제품 단계에서는 아래 정책을 정한다.

| 결정할 것 | 제안 |
| --- | --- |
| 참가 범위 | 초대받은 사람만, 공개 피드나 검색 없이 작은 모임 중심 |
| 봉인 | 참여 마감과 봉인을 분리하고 각자 동의를 기록 |
| 개봉 조건 | 사용자 요청대로 N명 전원 참석 필수. 기기 분실·영구 불참 시 현재는 열 수 없으며, 예외 정책은 사용자 합의와 별도 승인 없이 우회하지 않음 |
| 장소 접근 불가 | 이전·폐업·안전 문제에 대한 합의 기반 장소 변경 절차 마련 |
| 관계 변화 | 나가기, 내 자료 삭제·차단 등 안전 장치를 먼저 설계 |
| 최소 기간 | 정식 서비스는 ‘최소 한 달’의 달력 기준·시간대를 서버에서 명확히 적용. 개발용 짧은 시간은 운영에서 분리 |
| 알림 | 독촉보다 ‘슬슬 그날이야’ 정도의 알림, 끄기 가능 |

유머는 닫힌 캡슐의 추측이나 친구를 놀리는 짧은 문구에 사용한다. 열지 못하게 협박하거나, 돈을 내면 시간·장소 잠금을 무시하게 하는 방식은 서비스의 약속을 훼손한다.

## 수익화 방향 — 검증 가설

핵심 기능은 함께 묻고 다시 만나는 경험으로 유지한다. 과금은 사용량보다 놀이와 실제 만남에 붙이는 편이 어울린다.

- 선택형 꾸미기: 두지 의상, 캡슐 외형, 모임 전용 편지지. 기본 개봉과 자료 접근은 과금 대상에서 제외한다.
- 재회 패키지: 카페·사진관 등과 연계한 선택형 쿠폰이나 촬영 상품. 예약·결제가 실제로 발생할 때 수수료를 검증한다.
- 모임용 테마: 여행 마지막 날, 동아리 방학 전처럼 가벼운 상황별 묻기 질문 묶음. 기본 질문은 무료로 제공한다.

현재 결제나 제휴 기능은 없다. 먼저 ‘캡슐 때문에 실제로 다시 만났는가’를 확인한 뒤 유료 선택률을 측정한다.
