# 삐라삐라삐 — 운영정책 및 출시 체크리스트

## 1. 운영 원칙

- 삐라라는 시각적 은유를 사용하지만 정치 선전물, 광고물, 불법 유인물을 허용하지 않는다.
- 사용자 간 관계 형성보다 안전한 우연한 발견을 우선한다.
- 실제 접근 가능한 공공장소만 낙하 후보로 승인한다.
- 신고는 게시 중단을 우선하고 사후 검토한다.

## 2. 이용권과 결제 정책

- 무료 이용권은 매일 한국 시간 0시에 1장 사용 가능 상태로 전환된다.
- 무료 이용권은 누적되지 않고 유료 이용권보다 먼저 사용된다.
- 유료 이용권은 1장 300원의 소모성 디지털 상품이며 미사용분은 이월된다.
- 결제창의 상품명, 수량, 최종 금액은 앱 내 안내와 일치해야 한다.
- 결제 완료 후 지급 실패 건은 미결 주문 복원으로 처리한다.
- 같은 주문을 중복 지급하지 않는다.
- 환불 주문은 정기 대사로 확인하고 미사용 잔액을 회수한다. 이미 사용된 경우 고객지원 정책에 따라 처리한다.
- 사업자 정보, 정산 정보, 환불 안내를 출시 전에 공개한다.

## 3. 콘텐츠 조치

| 분류 | 기본 조치 |
|---|---|
| 연락처·SNS·주소·만남 | 작성 차단 |
| 광고·거래·정치 선전 | 작성 차단 |
| 협박·범죄 예고 | 작성 차단, 반복 시 이용 제한 |
| 혐오·괴롭힘 | 작성 차단 또는 신고 즉시 숨김 |
| 개인정보 노출 | 즉시 삭제 |
| 긴급 위험 | 보존 정책에 따라 증거 보전 및 관계기관 협조 |

## 4. 지역 안전 운영

- 현장 조사 또는 관리기관 공개자료로 안전 후보를 검수한다.
- 차도, 주차장 출입구, 철도, 수변 난간, 공사장, 사유지, 학교·병원 민감구역을 제외한다.
- 야간에는 조명이 확보된 장소만 활성화한다.
- 기상특보, 행사 혼잡, 사고 발생 시 구 단위 탐색을 즉시 중지한다.
- 사용자가 화면을 보며 이동하지 않도록 탐색 시작과 카메라 화면에 경고한다.

## 5. 개인정보

- 원본 익명 식별키를 저장하지 않는다.
- 정확한 위치는 획득 판정에만 사용하고 분석 이벤트에 포함하지 않는다.
- 삐라 본문은 암호화해 저장한다.
- 보유기간과 파기 주기를 개인정보 처리방침에 명시한다.
- 앱인토스 권한 설명, 서비스 화면, 처리방침의 문구를 일치시킨다.

## 6. 출시 체크리스트

### 제품

- [ ] 서비스명과 아이콘 확정
- [ ] 답장 불가와 한 사람만 획득 정책 노출
- [ ] 무료 1장 및 300원 가격 명확히 노출
- [ ] 빈 상태, 로딩, 권한 거부, 경쟁 패배 화면 확인

### 결제

- [ ] 사업자 및 정산 정보 승인
- [ ] 300원 소모품 SKU 등록
- [ ] iOS·Android 샌드박스 성공·취소·실패 테스트
- [ ] 서버 지급 실패와 미결 주문 복원 테스트
- [ ] mTLS 주문 검증과 인증서 교체 절차 확인
- [ ] 환불 대사와 잔액 회수 작업 확인

### 안전과 법률

- [ ] 위치기반서비스 관련 신고·약관 법률 검토
- [ ] 개인정보 처리방침 및 운영정책 공개
- [ ] 지역별 안전 후보점 현장 검수
- [ ] 신고 대응 시간과 긴급 대응 연락망 확정
- [ ] “삐라” 명칭의 심사·브랜드 리스크 검토

### 기술

- [ ] PostgreSQL/PostGIS 전환
- [ ] KMS 암호화 키 및 비밀 저장소
- [ ] WAF, 속도 제한, 모니터링, 백업
- [ ] 운영 시뮬레이션 기능 비활성화
- [ ] 동시 획득과 주문 중복 부하 테스트
- [ ] AIT 번들 용량과 최신 토스앱 호환성 확인
