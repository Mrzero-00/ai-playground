# "루프 켜줘" / "루프 꺼줘" — 어느 PC에서든 자동 루프를 같은 설정으로 (사용자 요청 2026-10-10)

> 사용자가 어느 PC에서든 **"루프 켜줘"**라고 하면 Claude가 아래를 순서대로 실행한다. 설정은 모두 이 저장소에 있으므로 `git pull`만 하면 같다.
> **한 번에 한 PC에서만** 켠다. 두 PC가 동시에 돌면 스캔기록·분석 결과가 충돌한다.

## 루프 켜줘
1. **다른 PC에서 돌고 있으면 먼저 끈다**: 사용자에게 "이전 PC에서 '루프 꺼줘'를 했는지" 한 줄로 확인한다(이전 PC 세션이 아직 열려 있으면 거기서 끄도록 안내).
2. `bash scripts/loop_start.sh` — git pull(pacu), 자동 수집(`autoscan.py`) 시작, 잠자기 방지(macOS `caffeinate`), 예약 표시 초기화, 새 회차 확인, 남은 블록 일정 출력.
3. Claude 예약 작업을 다시 건다(예약은 세션 한정이라 PC·세션이 바뀌면 사라진다):
   - 정기 작업(반복): cron `2 0,12 * * *` — 프롬프트 `[정기 작업: 회차 감시 00·12시] 승부예측 프로그램 폴더의 블록분석_절차.md A 절차를 그대로 수행해줘 (pull → round_watch.py check → plan → 블록 분석 예약/즉시 분석 → 정기 작업 만료 확인 → 커밋·푸시 main, main:pacu). 새 회차가 없고 예약할 블록도 없으면 한 줄만 보고.`
   - `round_watch.py plan`의 대기 블록 중 **다음 12시간 안**에 분석 시각이 오는 블록마다 일회성 작업(분석 시각 2분 전, :00/:30 피함) — 프롬프트 `[블록 분석] <회차>회 "<블록>" — 블록분석_절차.md B 절차대로. 끝나면 round_watch.py done <회차> "<블록>" 후 커밋·푸시(main, main:pacu).` → `분석일정.csv` 메모 '예약됨'. 분석 시각이 이미 지났고 마감 전이면 바로 B 절차.
   - `구매일정.csv`의 '대기' 조합 중 점검시각이 남은 것마다 일회성 최종 점검 작업(점검시각 6분 전).
4. 이 PC에서 사용자가 직접 할 일을 안내한다(PC마다 따로 저장되는 설정):
   - `/config agentPushNotifEnabled=true` (휴대폰 알림)
   - `/remote-control` (휴대폰·웹에서 이 세션 보기)
   - 터미널 창은 닫지 말고 최소화, 노트북 덮개 닫지 않기, 전원 연결.
5. 결과 보고: 켜진 것(자동 수집·잠자기 방지·정기 작업·예약된 블록 목록)을 표로. 변경 파일 커밋·푸시.

## 루프 꺼줘
1. `CronList` → 이 세션의 정기·일회성 작업을 모두 `CronDelete`.
2. `bash scripts/loop_start.sh stop` — 자동 수집·잠자기 방지 중지.
3. `python3 scripts/round_watch.py unreserve` → 커밋·푸시(다른 PC가 이어받을 수 있게).

## 참고
- 절차 본문: `블록분석_절차.md` (A 정기 감시, B 블록 분석), 구매 직전 점검: `scripts/final_check.py`.
- Windows PC라면 `loop_start.sh` 대신 같은 단계를 PowerShell로: `git pull`, `Start-Process python scripts/autoscan.py`, 전원 옵션 절전 '안 함'.
