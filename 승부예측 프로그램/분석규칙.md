# 분석 규칙 (누적)

회고를 통해 쌓이는 판단 기준이다. 예측 전에 반드시 읽고 적용한다.
형식: `- [신뢰도] 규칙 내용 — 근거 회차 / 추가일`

## 확률 결합 방식 (분석방법론.md 기반)
- [높음] 배당이 있으면 최종 = 시장(Shin 마진 제거) **90%** + 모델·뉴스 10%. 백테스트(5대 리그 2,623경기)에서 시장 70%는 시장 단독보다 유의하게 나빴고(z=3.1), 95%는 차이가 없었다 — 백테스트 2026-09-30
- [높음] 결장·라인업 뉴스는 경기 확률을 4%p 이상 바꾸는 경우가 약 21%뿐이고, 배당에 반영된 뒤에는 남는 가치가 없다. 뉴스 검색의 목적은 (1) 아직 배당에 반영되지 않은 결장·로테이션 예상, (2) 불확실성이 큰 경기를 골라 복수 마킹 후보로 올리는 것이다 — 백테스트 2026-09-30 (방법론 6-4)
- [높음] 모델 10%는 방향 힌트다. 시장에 없는 새 정보(라인업, 결장)가 있을 때만 5%p 이내로 더 움직인다 — 백테스트 2026-09-30
- [중간] 여러 배당사 평균(마감)이 Pinnacle 단독보다 근소하게 좋았다. 배당을 여러 곳에서 찾을 수 있으면 평균도 함께 본다 — 백테스트 2026-09-30
- [중간] 하루 전 배당(오픈)만 있을 때도 모델을 5~15% 이상 섞으면 나빠졌다. 오픈 배당 95% + 모델 5%로 시작한다 — 백테스트 2026-09-30
- [높음] 시장과 8%p 이상 차이 나면 명확한 근거(시장 반영 전 라인업 등)가 없는 한 시장 쪽으로 되돌린다 — 2026-09-28
  - 근거 추가(119회): **출전 '의문' 선수를 결장으로 가정**해 순수를 시장보다 9~13%p 높인 2경기가 모두 실패 — DB(LG 타마요·양준석 출전, 96-92 LG), 화이트삭스(위 불펜데이). 의문 선수는 출전 확정 전까지 시장 수준으로 두고, 확정 결장 뉴스가 나오면 그때 반영한다. `round_log.py adjust`가 8%p 이상 차이를 경고한다 — 2026-10-09
- [높음] 폼은 결과가 아니라 xG/xGA(야구는 FIP/xFIP)로 보고, 표본이 적으면 리그 평균 쪽으로 당긴다 — 2026-09-28
- [높음] 홈/원정 분리 xG를 쓸 때는 `--split`으로 홈 이점 중복을 막는다 — 2026-09-30
- [높음] 배당이 있는 경기는 시장 확률(m_win, m_draw, m_lose)을 예측기록에 반드시 남긴다. 실력 검증은 적중률이 아니라 시장 대비 RPS로 한다 — 2026-09-30
- [높음] 유료 픽·커뮤니티의 적중률 주장은 근거로 쓰지 않는다 (검증 후 수익률 17% → 1% 사례) — 2026-09-30
- [중간] 국내 배당은 기준선으로 쓰지 않는다. 해외 배당과 비교하는 용도로만 본다 — 2026-09-30

## 확신 지표 = 1·2순위 차 (2026-10-23, 125회 심층회고 — `analysis_guard.py`)

- [높음] **내 1순위 확률의 절대값은 확신 지표가 아니다. 1·2순위 차(margin)가 확신 지표다.** 전수 측정(n=593, 순수 1순위): 차 0~3%p **33.3%** · 3~6%p **32.7%** · 6~10%p **47.2%** · 10~20%p **50.0%** · 20%p+ **65.5%** — 확률 절대값과 달리 **단조**다 — 125회 회고 / 2026-10-23
- [높음] **차 10%p 미만은 '방향을 고른 것'이 아니라 '형성되지 않은 것'이다. 확신도를 `기권`으로 적는다.** 확률·방향 기록은 그대로 남긴다(표본을 버리지 않는다). 깊이=기준선 × 차<10%p 는 29건 **17.2%**. `baseline_fill.py`가 자동으로 적고 `round_log.py anchor`가 검문한다 — 125회 9811(차 0.0)·9901(차 0.4)·9672(차 2.8)·9639(차 3.0)·9794(차 6.8) / 2026-10-23
- [중간] 이 문턱을 **추천(`pick_table.leg_type`)에는 쓰지 않는다** — 코어 통과 다리 중 차 3~8%p 6다리가 83.3%로 분포가 다르다. 기존 기권 가드(차<1%p)는 그대로 둔다 — 2026-10-23
- [높음] 기존 점검표 항목 "차 1%p 미만이면 기권"은 **문턱이 너무 낮았다**(1%p 아래는 거의 생기지 않는다). 10%p가 측정값이다 — 2026-10-23

## 심판·날씨 열은 채워지는 시점이 다르다 (2026-10-23, `context_inputs.py`)

- [높음] **`context_inputs fill` 은 두 번 돌린다.** ESPN 캐시에는 끝난 경기만 있어서 판매 중 회차에 돌리면 아무것도 안 채워졌다 — 126회 133경기 → 0건, 누적 **심판 0/960 · 날씨 8/960** 으로 사실상 죽은 기능이었다(2026-10-22에 넣은 개선안 5번) — 2026-10-23
  - **날씨**(분석에 쓰는 사전 입력): 이제 ESPN venue 가 없으면 **홈팀 구장 좌표**(venue_env/Wikidata 캐시)로 돌아간다. 고친 뒤 126회 **124/174 경기**가 경기 전에 채워졌다. → **판매 중 회차**에 돌린다.
  - **심판**(사후 집계용): ESPN 경기 요약에만 있어 **끝난 뒤에야** 채워진다. 사전 입력이 아니라 `refstats`(심판별 무 비율)를 쌓기 위한 열이다. → **회고 때 직전 회차**에 돌린다.
- [중간] 넣은 기능이 실제로 값을 쌓고 있는지 **열 채움 수를 세어 확인한다**. 0/960 이 한 달 가까이 아무도 모르게 지나갔다 — 기능을 넣은 회고의 다음 회고에서 채움 수를 한 줄 확인하는 것으로 족하다 — 2026-10-23

## 좁은 확률 칸의 '유의'를 믿지 않는다 (2026-10-23, 125회 심층회고 — `calib_report.py`)

- [높음] **5%p 폭 확률 칸의 '유의 편향'은 칸 경계를 옮겨 다시 재기 전에는 편향이 아니다.** 보정 60~65% 가 말 62.7% / 실제 46.4% (z=−2.2) 로 유의하게 찍혔지만, 같은 모집단을 **10%p 폭**으로 묶으면 45~55 50.8% · 55~65 55.6% · 65~101 73.5% 로 단조롭고 전부 |z| ≤ 1.0 이며, **경계를 5%p 옮기면 구멍이 50~60(61%)→60~70(53%)으로 자리를 옮긴다**. 구멍이 확률값에 붙어 있지 않으면 확률의 문제가 아니다 — 5%p 칸은 n≈50 이라 ±7%p 가 그냥 흔들린다 — 2026-10-23
- [높음] **없는 편향을 쫓아 멀쩡한 입력을 건드리는 것이 가장 비싼 실수다.** `calib_report.py` 가 이제 유의 표시를 올리기 전에 경계를 ±5%p 옮겨 재검하고(`robust_band`), 살아남지 못하면 `경계 흔들림` 으로 내린다. 이웃 구간 역전도 10%p 칸에서 살아남을 때만 올린다 — 2026-10-23
- [중간] 이 수정 뒤에도 **순수 쪽 역전은 남는다**(45~50 68.7% > 50~55 60.2%). 이건 진짜이고 원인도 안다 — 절대 확률이 아니라 **1·2순위 차**가 확신 지표라서다(그 구간 차 중앙값 19.6%p). 보정 쪽 역전은 사라졌다 — 보정 계층은 지금 잘 맞고 있다 — 2026-10-23

## 보정 계층은 분석 행에만 (2026-10-23, 125회 심층회고 — `round_log.cmd_anchor` · `analysis_guard` G6)

- [높음] **깊이=기준선 행에는 보정 계수를 적용하지 않는다.** `calibrate.py` 는 계수를 분석 행으로만 학습하는데(fit 에서 기준선 제외) 적용은 전 행에 하고 있었다. 기준선은 뉴스·결장이 안 들어간 평평한 모델 출력이라 T=1.27·홈 +0.193 으로 날을 세우면 없는 확신이 생긴다. 실측(축구 기준선 135경기): 미적용 RPS **0.2057**·말 50.7% vs 적용 RPS 0.2118·말 57.0% — RPS **+0.0061 악화**, 과신 **+8.9%p**. 방향별로도 기준선은 이미 정합이라(승 말 42.0/실제 39.3, z=−0.7) 홈 편향을 더할 이유가 없다 — 125회 9909(61.8→75.3, 시장 57.8, 0:1 패)·9936(65.4→79.0, 시장 56.7, 1:2 패) / 2026-10-23
- [높음] **분석 행에서는 보정이 계속 이득이다** — 1순위 54.6→56.3% · RPS 0.2094→0.2052 (n=465). 보정 자체를 끄는 게 아니라 **적용 범위**를 학습 범위와 맞춘 것이다 — 2026-10-23
- [높음] **깊이 칸을 비운 채로 확률을 확정하지 않는다.** 깊이는 학습 분리 스위치라 칸이 비면 모델 자동 채움이 분석 행으로 둔갑해 조용히 학습에 섞인다(125회 UECL·UEL 18경기가 그랬고 보정 계수 교차검증 이득이 0.0026→0.0006 으로 깎여 있었다). `analysis_guard` **G6** 가 막고, 기준선 표식이 있으면 자동 교정한다 — 2026-10-23

## 결장 가산을 쓸 때 (2026-10-23, 125회 심층회고)

- [중간] **결장이 한 포지션군에 3명 이상 몰리면 '자체 결장 합계 상한'을 적용하지 않는다.** 분산 결장과 달리 라인이 통째로 무너지므로 감점을 깎지 말고 **방향 자체를 재검토한다** — 125회 9941 셀틱 CB 3명(Carter-Vickers·Johnston·Trusty) 동시 결장을 근거로 적고도 상한에 깎여 홈 승 47.1 을 1순위로 유지 → 실제 Scales·Dane Murray·Tierney 땜질 라인, 셀타 슈팅 22-8·점유 56%로 1:2 패 / 2026-10-23
- [중간] **전력 격차 20%p 이상인 강팀 원정의 결장 가산으로 기준선 격차를 좁히지 않는다** — 벤치 깊이가 손실을 흡수한다 — 125회 9977 소시에다드 3명(Odriozola·Aramburu·Herrera) 결장에 홈 +1.8%p 를 줬는데 **0:6** / 2026-10-23
- [낮음·관찰] 핸디캡 다리 방향이 **내 1X2 1순위와 반대**이고 내 1X2 1순위가 70%+ 이면 4/11(36%) — 같은 방향 59.5%·반대 전체 59.6% 대비 나쁘다(125회 9947 본머스: 승 72.2% 를 적고 '2골차로는 못 이긴다' 쪽에 걸어 3:0 으로 실패). **다만 핸디캡 확률 전수는 정합이라**(n=91, 말 58.9%/실제 59.3%, z=+0.1) 규칙으로 만들지 않고 관찰로 둔다. 재측정 기준 이 포켓 25다리 — 2026-10-23

## 시장과 갈릴 때 (2026-10-23, 125회 심층회고 — `analysis_guard.py` G3)

- [높음] **내 1순위 ≠ 시장 1순위면 모든 gap 구간에서 진다.** 갈림 95건 **내 29.5% vs 시장 44.2%(−14.7%p)**. 세부: +15%p↑ 15건 26.7% vs 60.0% · +2~8%p 36건 27.8% vs 47.2% · 깊이=심층 갈림 14건 21.4% vs 57.1% — 2026-10-23
- [높음] **시장 숫자를 베끼지는 않는다**(사용자 지시 2026-10-19). 대신 **증거 요건**을 건다 — 갈린 근거가 '확인된 사실'(공식 결장·발표 라인업·팩트시트 사실)이 아니면 기준선·시장 합의 쪽으로 되돌린다. `analysis_guard.py` G3가 갈림 & gap≥+15%p를 경고 — 125회 9827 헤타페(+21.5%p → 2:5 패) / 2026-10-23
- [높음] **결장 1건으로 시장과 +8%p 이상 벌리지 않는다.** 125회 9677 바이에른−아스널: Saliba 결장 하나로 52.6→55.0(시장 43.0, +12.0%p 갈림) → 실제 유효 5:5·2:2 무. 124회 포르투−PSV와 같은 항목(중복 가산 금지) — 2026-10-23

### 2. [중간] 1X2 가 과신이어도 λ 전개로 코어 다리가 나온다 — 경기당 전 선택지를 판정한다
