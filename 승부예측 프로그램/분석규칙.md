# 분석 규칙 (누적)

회고를 통해 쌓이는 판단 기준이다. 예측 전에 반드시 읽고 적용한다.
형식: `- [신뢰도] 규칙 내용 — 근거 회차 / 추가일`

## 확률 결합 방식 (분석방법론.md 기반)
- [높음] 배당이 있으면 최종 = 시장(Shin 마진 제거) **90%** + 모델·뉴스 10%. 백테스트(5대 리그 2,623경기)에서 시장 70%는 시장 단독보다 유의하게 나빴고(z=3.1), 95%는 차이가 없었다 — 백테스트 2026-09-30
- [높음] 결장·라인업 뉴스는 경기 확률을 4%p 이상 바꾸는 경우가 약 21%뿐이고, 배당에 반영된 뒤에는 남는 가치가 없다. 뉴스 검색의 목적은 (1) 아직 배당에 반영되지 않은 결장·로테이션 예상, (2) 불확실성이 큰 경기를 골라 복수 마킹 후보로 올리는 것이다 — 백테스트 2026-09-30 (방법론 6-4)
- [높음] 모델 10%는 방향 힌트다. 시장에 없는 새 정보(라인업, 결장)가 있을 때만 5%p 이내로 더 움직인다 — 백테스트 2026-09-30
- [중간] 여러 배당사 평균(마감)이 Pinnacle 단독보다 근소하게 좋았다. 배당을 여러 곳에서 찾을 수 있으면 평균도 함께 본다 — 백테스트 2026-09-30
- [중간] 하루 전 배당(오픈)만 있을 때도 모델을 5~15% 이상 섞으면 나빠졌다. 오픈 배당 95% + 모델 5%로 시작한다 — 백테스트 2026-09-30
- [높음] 시장과 8%p 이상 차이 나면 명확한 근거(시장 반영 전 라인업 등)가 없는 한 시장 쪽으로 되돌린다 — 2026-09-28
  - 근거 추가(119회): **출전 '의문' 선수를 결장으로 가정**해 순수를 시장보다 9~13%p 높인 2경기가 모두 실패 — DB(LG 타마요·양준석 출전, 96-92 LG), 화이트삭스(위 불펜데이). 의문 선수는 출전 확정 전까지 시장 수준으로 두고, 확정 결장 뉴스가 나오면 그때 반영한다. `round_log.py adjust`가 8%p 이상 차이를 경고한다 — 2026-10-09
- [높음] 폼은 결과가 아니라 xG/xGA(야구는 FIP/xFIP)로 보고, 표본이 적으면 리그 평균 쪽으로 당긴다 — 2026-09-28
- [높음] 홈/원정 분리 xG를 쓸 때는 `--split`으로 홈 이점 중복을 막는다 — 2026-09-30
- [높음] 배당이 있는 경기는 시장 확률(m_win, m_draw, m_lose)을 예측기록에 반드시 남긴다. 실력 검증은 적중률이 아니라 시장 대비 RPS로 한다 — 2026-09-30
- [높음] 유료 픽·커뮤니티의 적중률 주장은 근거로 쓰지 않는다 (검증 후 수익률 17% → 1% 사례) — 2026-09-30
- [중간] 국내 배당은 기준선으로 쓰지 않는다. 해외 배당과 비교하는 용도로만 본다 — 2026-09-30

## 적중 확률 극대화 규칙 (2026-10-02 백테스트, 사용자 목표: 가장 잘 맞히는 방법)
근거 파일: `회차별분석/확률방식비교_2026-10-02.md`, `80선별_백테스트_2026-10-02.md`, `상수점검_2026-10-02.md` (EPL 2012-13~2025-26, 5,320경기)
- [높음] **확률의 기준은 Pinnacle 마감(경기 직전) 배당이다.** 오픈(하루 전) 배당은 유의하게 덜 정확했다(RPS z +3.2). 사기 전 킥오프 1~3시간 안에 `odds_scan.py --best`를 다시 돌린다 — 확률방식비교 / 2026-10-02
- [높음] 시장 확률을 모델로 고치지 않는다. 재보정(z +0.7)·Elo/pi 스태킹(z +1.4) 모두 시장 마감보다 좋지 않았다. 50~90% 구간 실제 적중이 예상과 ±3%p 안(z<1.2)이라 고확률 선택도 그대로 믿는다 — 상수점검·확률방식비교 / 2026-10-02
- [높음] **경기마다 일반 승무패만 보지 말고 핸디캡·언더오버까지 전부 계산해 확률이 가장 높은 선택지 1개를 고른다.** EPL 공통 660경기: 일반만 56.8% → 정수·소수핸디캡 포함 58.6% → 언더오버 2.5 포함 **64.2%**. 117회 실제 48경기 평균 61.0% → 66.6% — 80선별 백테스트 / 2026-10-02
- [높음] 베트맨 정수핸디캡은 유력팀에 -1이 걸린다. '지지 않으면 적중'은 약팀 쪽(H-1 패 / H+1 승)만 있고 유력팀 쪽은 없다. 백테스트도 이 구조로만 계산한다 — 2026-10-02
- [중간] 확률 기준 선별: 최고 선택지 확률 80%+인 경기는 실제 86.1%(287경기)였지만 전체의 5.4%뿐이다. 70%+ 17.8% 경기 → 실제 78.2% — 80선별 백테스트 / 2026-10-02
- [중간] Pinnacle에 그 핸디캡·언더오버 라인이 없으면 승무패 + 기본 언더오버로 기대득점을 역산(Dixon-Coles rho -0.06)해 계산한다. EPL 660경기 x.5 핸디캡 Brier 0.2510 = 시장 0.2511 — 상수점검 / 2026-10-02
- [중간] 역산 모델은 한쪽 승 확률 90% 이상 경기에서는 쓰지 않는다(점수 꼬리 외삽, EPL 표본 19경기). 첫 구현의 탐색 범위(약 2.6골) 버그로 인도-브라질 H+3 승이 78%(실제 시장 약 25%)로 나온 사례가 있어 범위를 0.1~6.7골로 넓히고 맞춤 오차 검사를 넣었다 — 2026-10-02
- [높음] 조합 적중 확률 = (각 선택 기대값의 곱) ÷ 합계 배당. 목표 배당이 정해지면 기대값 높은 선택을 적게 묶을수록 잘 맞는다(`--target`이 그렇게 고른다) — 수학적 사실 / 2026-10-02
- [중간] **뉴스 위험을 확인한 경기는 순위만 내리지 말고 추천에서 뺀다** (`data/exclude.json`). 117회 한국 배구(8강 탈락 후 순위결정전)를 위험 표시만 하고 남겼다가 1-3 패 — 117회 회고 / 2026-10-05
- [관찰] 유력팀 일반 승(1.1~1.7)이 무승부로 끝난 사례 **7건**(118회 몬테네그로 0-0·에콰도르 1-1 추가)(프랑스 1-1, 일본 0-0, 몰타 1-1 / 116회 10/1~2: 아제르바이잔 0-0(85%), 한국 0-0(57%)). 누적 51경기 무 예측 평균 12.4% vs 실제 18.0%. 시장 무 확률 범위 안이라 규칙은 보류하되, 승무패형 단식에서 60% 미만 '승'은 사지 않는다는 기존 기준을 유지 — 117회 회고 / 2026-10-05, 116 후속 회고 / 2026-10-06
- [중간] 야구·배구·농구는 과거 배당 자료가 없어 보정을 직접 검증하지 못했다. 같은 Pinnacle 방식이라 축구와 비슷하다고 가정하고, 예측기록으로 누적 검증한다 — 2026-10-02

- [폐기 → 수정] ~~승무패는 이월금이 판매액 절반을 넘는 회차에만 산다~~ 판매 중 스냅샷 판매액으로 판단하면 틀린다. 최종 판매액은 마감 직전에 폭증한다(57회: 10/1 오후 2.92억 → 최종 27.4억). 베트맨 결과 조회로 확인한 실제 수치 — 55회 판매 43.1억·이월 19.8억(3회 누적) → 전체 환급 (21.5+19.8)/43.1 = **0.96**, 57회 판매 27.4억·이월 3.3억 → (13.7+3.3)/27.4 = **0.62**. 이월 1회(3억대)는 평균 티켓 기대값을 0.50→0.62로 올릴 뿐이다. **새 기준: 이월 누적액이 15억 이상(최종 판매액의 절반에 근접)일 때만 승무패를 검토**하고, 그때도 대중 투표가 몰리지 않은 선택지(가치 1.2 이상)로 구성해야 1.0을 넘길 여지가 있다 — 2026-10-06 (tracker/베트맨 G011 조회)
