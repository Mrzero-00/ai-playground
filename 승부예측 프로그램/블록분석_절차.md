   - 블록 경기 전체 분석표: 순수·뉴스 갱신 후 `python3 scripts/block_report.py <회차> "<블록>"` → `회차별분석/블록분석_<회차>_<MMDD-HHMM>.md` (기준선·순수·시장·최종·최고 선택지·근거·뉴스위험·추천/제외). 6단계 저장 뒤 한 번 더 돌려 추천/제외 칸을 채운다.
4. `odds_scan.py --round <회차> --best --log --close-from "<첫마감>" --close-to "<끝마감>"` → 이 블록 후보만.
5. 조합 고르기: 최종 확률 확정 **후** 시장과 비교해 **유형 A(갈림: 확인된 사실 근거) 또는 B(일치: 내 60%+·시장 60%+) — 기대값 조건은 2026-10-16 사용자 결정으로 폐지** 다리만, 배당 1.2 이상(2026-10-15), 라인업 위험 경기 빼기, **비슷한 시각에 끝나는 경기끼리** 2~3경기, 1~3조합. 조합 안 경기 종료 예상 차이는 90분 이내(`pick_table.py` 경고).
   - **다리 수(사용자 지시 2026-10-12)**: 2다리 조합을 기본(적중 확률 최대)으로 하되, 3~4다리 다중 조합도 1개 함께 추천한다(적중 확률·배당 나란히, 다중은 확률이 2다리의 절반 이하임을 표시).
6. `pick_table.py --round <회차> --save "제목=번호:선택,..." --skip "번호:선택=이유" ...`
   - 조합 마감이 분석 시각 + 60분보다 늦으면(같은 블록의 늦은 경기) 그 조합의 점검시각에 `CronCreate` 일회성 최종 점검(`final_check.py` + 라인업 확인 + PushNotification)을 건다.
6-1. **금액 배분 (사용자 지시 2026-10-13: 회차당 10만원 전부 사용)**: `python3 scripts/budget.py <회차> "<제목>=<적중확률>:<다리수>" ...` (회차 마지막 블록이면 `--last`) → 조합마다 💰 금액을 표 아래에 붙인다.
7. 사용자에게는 **추천 조합 표만** 보여 준다(🕒 구매 시각 포함). 뺀 경기 설명은 하지 않는다. 추천이 없으면 '추천 없음 — 블록 N경기 분석 기록(파일명)' 한 줄.
8. `PushNotification` 한 줄: 예) "120회 10/10 오후 블록: 2조합 추천, 구매 13:30까지".
9. `round_watch.py done <회차> "<블록>"` → **커밋·푸시(main, main:pacu)**.

## C. 회고
회차가 끝나면 사용자가 "회고 진행해줘"라고 할 때 기존 회고 절차(CLAUDE.md 모드 2)를 따른다. 자동 루프는 회고를 하지 않는다.
