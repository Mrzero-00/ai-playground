# 조사 에이전트 프롬프트 (심층 분석 강화, 사용자 승인 2026-10-12)

> 블록 분석(B-2)·승무패 분석 때 조사 에이전트에 아래 블록을 붙인다. 종목 체크리스트(`종목별분석/<종목>.md`)와 `변수태그.md`도 함께 붙인다.
> 배당은 보지 말라고 지시한다(순수 분석). 결론은 승/무/패 % + 근거 + 출처.

## 1차 조사 (모든 경기)
```
[필수 항목]
1. 결장 영향 숫자화 — 결장/의문 선수마다: 포지션, 이번 시즌 출전시간 비중(%), 득점·도움(또는 xG+xA) 팀 내 비중(%), 대체 선수.
   포지션 가중치: 주전 GK·주전 CB·주포(팀 득점 25%+)는 '핵심', 나머지 주전은 '주요', 로테이션 자원은 '경미'.
   결론에 "결장 영향: 홈 핵심 n·주요 n / 원정 핵심 n·주요 n"을 한 줄로 쓴다. '확정'과 '의문'을 구분한다(의문은 0으로 계산).
2. 최근 5경기 폼(결과·득실·가능하면 xG), 홈/원정 성적, 맞대결 최근 5경기.
3. 일정 피로(직전·다음 경기 간격, 주중 대회, 이동), 동기(순위 경쟁·확정 여부), 감독·내부 이슈.
4. 무승부 근거: 두 팀 최근 득점 수준, 맞대결 무 비율, 예상 총득점 높낮이.
5. 이변 시나리오: 유력팀이 지지 않을/못 이길 구체적 이유 1~2개.

[출처]
- 영어 매체에 더해 **현지 언어 매체를 반드시 1곳 이상** 검색한다(결장·라인업 소식이 몇 시간 빠르다):
  스페인 Marca·AS·Mundo Deportivo·구단 지역지(Noticias de Navarra 등) / 이탈리아 Gazzetta·Corriere dello Sport·구단 전문지 /
  독일 kicker·Sportschau·구단 지역지 / 프랑스 L'Équipe·Ouest-France·Maxifoot / 네덜란드 VI·NOS /
  일본 스포니치·닛칸스포츠·구단 공식 / 한국(KBO·KBL·K리그) 담당 기자 기사·구단 공식 SNS 보도.
- 같은 사실이 매체마다 다르면(예: '5연패 무득점') 두 곳 이상에서 확인될 때만 쓰고, 아니면 "미확인"이라고 쓴다.
```

## 2차 반론 조사 (추천 후보·8%p 갈림·3%p 박빙 경기)
```
이 경기에서 현재 판단은 <선택>(<확률>%)이다. 이 선택이 틀릴 이유를 찾는 데 집중하라.
- 1차에서 놓친 결장·복귀·라인업 변화, 상대의 강점이 통하는 전술 상성(압박 vs 빌드업, 포메이션 상성, 세트피스).
- [박빙 경기만] 세부 변수: 주심 성향(경기당 카드·페널티), 날씨·잔디, 이동거리, 주중 경기 출전시간.
결론: 판단 유지/수정 + 수정 시 승/무/패 %.
```

## 앙상블 (추천 후보·3%p 박빙 경기만 — 토큰 2~3배라 전체에는 쓰지 않음)
- 같은 경기를 **서로 결과를 모르는 에이전트 2개**에 1차 프롬프트로 따로 맡긴다(병렬).
- 최종 판단 = 두 결과 평균(+ 기존 1차). **두 에이전트의 1순위 확률 차가 10%p 이상이거나 1순위가 다르면 '불확실'**:
  프로토는 추천에서 빼고, 승무패는 그 경기를 복수 마킹 후보로 올린다.
- 사실 관계가 서로 다르면(한쪽만 결장 보도) 그 사실만 한 번 더 확인한다.

## 배당 흐름 신호 (스크립트, 비용 없음)
- `python3 scripts/market_move.py <회차> [번호 ...]` — 첫 수집 대비 최신 Pinnacle 공정확률 이동.
  '순수 쪽 ✓' = 시장도 같은 정보를 반영(확신 유지), '순수 반대 ⚠ 재조사' = 내가 모르는 정보 가능성 → 2차 반론 대상에 넣는다.
- 120회 소급: 팰리스-노팅엄은 시장이 노팅엄 쪽으로 움직였지만 순수(무 39%)와 반대 신호였고 결과는 팰리스 승 — 신호는 근거 중 하나일 뿐 결과 판정은 회고에서 누적한다.
