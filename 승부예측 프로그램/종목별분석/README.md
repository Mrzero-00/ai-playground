# 종목별·리그별 분석 기법 (사용자 제안 2026-10-09)

> 축구·야구·농구·배구는 이기는 원리가 달라 필요한 변수도 다르다. 공통 규칙(`분석규칙.md`)은 그대로 두고,
> 종목마다 **기준선 만드는 법 → 조사 체크리스트 → 알려진 편향 → 리그별 차이**를 이 폴더에 따로 둔다.

|---|---|
| `축구.md` | K리그1·2, J1·J2, EPL·챔피언십, 분데스리가, 라리가, 세리에A, 리그1, 에레디비시, MLS, CSL, A리그, ACL |
| `야구.md` | KBO, MLB(포스트시즌), NPB(클라이맥스 시리즈) |

| `성공률_향상_로드맵.md` | 리그별 80% 목표까지의 단계·지표·학습 루프 (2026-10-09) |

## 쓰는 법
1. 순수 분석(배당 보기 전) 때 조사 에이전트 프롬프트에 **해당 종목 파일의 '조사 체크리스트'와 해당 리그 절을 그대로 붙인다.**
2. 순수 확률은 그 종목의 **기준선 방법**으로 먼저 만들고, 체크리스트 변수로 정해진 폭 안에서만 움직인다.
3. 회고 때 `own_model.py report`의 리그별 표(순수 vs 시장 RPS)를 보고, 맞은 변수·틀린 변수를 **해당 종목 파일의 리그 절**에 적는다. 공통으로 2~3회 반복되면 `분석규칙.md`로 올린다.
4. 리그별 순수 비중(w)은 `data/own_weights.json`에 리그→종목→전체 순서로 따로 저장된다(이미 자동).
