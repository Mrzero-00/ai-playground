# 결장 → 대체 → 라인업·포메이션 → 상성 세부 분석 (2026-10-15, 사용자 요청)

> 사용자 요청: "결장 선수가 주축인지 영향도를 따지고, 완전 주축이면 더 큰 감점, 주축이어도 대체 선수가 괜찮으면 영향이 작을 수 있는 모든 가능성", "빠짐으로써 예상되는 라인업·포메이션을 상대와 비교".
> 계기: 122회 셀타-유벤투스 — '결장 6명'이라는 이름 수로 A 갈림 판정 → 이번 시즌 선발 비중 확인 결과 대부분 시즌 내내 이탈(이미 반영), 오히려 셀타 주축 2명 이탈 → 철회.
> 근거 수준: 아래 숫자는 **대부분 초기값(판단)**이다. 근거로 확인된 것은 [근거], 나머지는 [초기값]. 결장영향기록으로 20~30건마다 재보정한다.

## 0. 공통 공식 (모든 종목)

**팀 결장 감점 = Σ 선수별 (등급 기본값 × 대체 격차 R × 상태 P × 신규성 D) × 다중 결장 보정**, 팀당 상한 적용 → 내 확률에 **우리 팀 감점 − 상대 팀 감점** 만큼 반영.

| 요소 | 정의 | 값 |
|---|---|---|
| 등급 | 그 선수의 **이번 시즌** 비중(선발·출전시간·득점 점유) — 이름값·작년 명성 아님 | 종목별 표(1~4절) |
| 대체 격차 R | 실제로 들어올 대체 선수 수준 | 동급 0.3~0.5 · 평균 0.6~1.0 · 열세 1.0~1.3 · 포지션 파괴(다른 포지션 차출) 1.2~1.5 |
| 상태 P | 출전 여부 | 확정 결장 1.0 · 의심(doubtful) 0.5~0.85 · 출전 불투명(questionable) 0.5 · 출전 가능성 높음 0.1~0.2 · 발표 라인업 제외 확인 1.0 / 포함 확인 0 |
| 신규성 D | 이미 팀 레이팅·최근 성적·시장에 들어간 정보인가 | 결장 3경기 이내(새 소식) 1.0 · 4~8경기째 0.5 · 8경기+ 장기 0.2 · **시즌 내내 이탈 0** |
| 다중 결장 | 같은 라인 2~3명 이상 | 2번째부터 ×1.15~1.2(뎁스 소진) · 스타 1명 단독은 ×0.85(동료가 사용률 흡수, 농구 [근거 방향]) |

- 신규성 D는 우리 기준선(Elo·pi-rating·최근 폼)이 그 결장을 이미 담았는지로 판단한다. 시장과 비교하는 단계(A 갈림)에서 장기 결장을 근거로 쓰지 않는 이유와 같다.
- **양 팀 모두 센다.** 한쪽 결장만 보고 판단하지 않는다(셀타 사례).
- 의심 선수를 결장으로 가정하지 않는다(119회 교훈) — P로만 반영.

## 1. 축구

**등급** (최근 8경기 기준, 시즌 초 8경기 미만이면 지난 시즌 값과 50:50) [초기값]
| 등급 | 조건 | 기본 감점(승 %p) |
|---|---|---|
| S | 출전시간 85%+ 이면서 팀 xG+xA 1~2위, 또는 팀 내 몸값 1위 주전 | 4.5 |
| A | 선발 75%+, 몸값 상위 3 | 3.0 |
| B | 선발 60%+ | 1.5 |
| C | 로테이션·백업 | 0 |
- 주전 GK는 한 등급 올린다(대체 격차가 가장 큼). CB·수비형 MF는 A 이상만 점수.
- 득점 쪽으로는 점수 1당 상대 승 +1.0, 무 +0.5로 나눈다(승 −1.5 : 상대 +1.0 : 무 +0.5 비율). [초기값]
- 팀당 상한 −8%p. [초기값]
- 근거: 선발 라인업 선수 레이팅 평균이 경기 예측 변수로 쓰임(Arntzen & Hvattum 2021), 몸값이 예측력 있음(Peeters 2018) [근거 방향]. 시즌 초 RAPM·on/off는 표본 부족으로 못 씀.

## 2. 야구 (KBO·MLB·NPB)

**타자** — 경기당 가치 = WAR ÷ 경기 수(MLB 162, KBO 144, NPB 143) [근거: 산식]
| 등급 | 조건 | 기본 감점 |
|---|---|---|
| S | WAR 페이스 5+ 또는 wRC+ 150+, 1~3번 | 3.5 (KBO ×1.12) |
| A | WAR 3.5~5, wRC+ 125~150 | 2.3 |
| B | WAR 2~3.5, wRC+ 100~125 | 1.2 |
| C | WAR 2 미만 | 0.3 |
- 대체: 백업이 대체수준이면 R 1.0, 평균 근처면 0.5. 포수는 백업 공격력이 매우 낮으면 +0.5%p. KBO 백업 질이 낮아 ×1.2. 2번째 결장부터 ×0.8, 타선 상한 −6%p. [초기값]
- **선발투수 교체가 가장 크다**: 당일 교체는 새 선발 WAR/등판·FIP로 재산정, 격차 ×0.5, 상한 ±8%p. 오프너·불펜데이는 팀 불펜 수준 + 불펜 소모 −0.5~1%p. [근거: 538 MLB 선발 보정 구조, 크기는 초기값]
- **불펜**: 마무리 불가 −0.5, 셋업 −0.3, 연투 피로 1명당 −0.2, 상한 −1.5%p. [초기값, 정량 연구 없음]
- 타순 배열 효과는 작다(시즌 2~15점) [근거: Tango]. 플래툰(상대 선발 좌우)이 더 크다.
- KBO 외국인: 1~2선발 외국인 결장은 +1.0%p 가산. 팀 성적과 외국인 WAR 비중이 비례하지 않으니 비중은 Statiz에서 팀별로 직접 합산. 팀당 전체 상한 −8%p.

## 3. 농구 (KBL·B.League·NBA)

점수(스프레드) 단위로 먼저 내고 승률로 바꾼다: **1점 ≈ 3.2%p**(접전 구간, 표준편차 12점 기준), 6점 넘으면 정규분포식 Φ(점수/12). [근거: 일반 모형]
| 등급 | 조건 | 기본 점수 |
|---|---|---|
| S | 팀 득점 점유 28%+ 또는 사용률 30%+, 리그 최상위급 | 3~5 (NBA 슈퍼스타 3~5.5점 [근거: 오즈메이커]) |
| A | 점유 20~28%, 30분+ | 1.5~3 |
| B | 점유 12~20%, 22~30분 | 0.5~1.5 |
| C | 22분 미만 | 0~0.5 |
- **KBL 핵심 외국인**(득점 점유 30%+ 또는 리바운드 1위급)은 S, 기본 4~6점. 두 번째 외국인 A. 외국인 1명 결장 시 남은 1명이 1·4쿼터 부담(2·3쿼터만 동시 출전 [근거: 규정, 26-27 유지 여부 확인]). 대체 외국인 합류 3경기 이내 ×0.8. [초기값]
- 출전시간 재분배: 결장자 분을 로테이션이 나눠 갖는다 — 538식 '현재 로테이션 vs 풀 전력 로테이션' 차이. [근거: 538 방법]
- 상한 NBA 8점, KBL·B.League 10점(약 ±25%p). 시장은 슈퍼스타 결장에 과잉 반응하는 경향 [근거: 업계 서술] → B 일치 다리 판단 때 참고.
- 농구는 조합 제외 종목(기록·검증용).

## 4. 배구 (V리그·KOVO컵)

| 등급 | 조건 | 기본 감점 |
|---|---|---|
| S | 주전 세터, 또는 팀 득점 비중 30%+ 외국인 아포짓 | 6 |
| A | 득점 비중 20~30% 아웃사이드/아포짓, 아시아쿼터 주전 | 3~4 |
| B | 주전 미들, 주전 리베로 | 2 |
| C | 로테이션 | 0~1 |
- 대체 격차: 대체 선수 지표(공격 효율·세트·리시브 효율)가 주전 대비 80%+ ×0.5, 보통 ×1.0, 60% 미만 ×1.5.
- **세터 이탈은 아포짓 효율을 먼저 깎는다**(정관장 PO 사례: 메가 공격 성공률 40%대→31% [사례 1건]). 대체 세터 주전 경험 없으면 +1%p, 아포짓 감점과 중복 합산 금지.
- 외국인 점유율 45%+ 팀의 외국인 이탈 ×1.25, 대체 외국인 합류 후 ×0.5.
- **컵대회는 감점 절반 + 불확실성 확대**(외국인 미합류·전원 결장·실험 기용 [근거: 2025 컵대회 규정]). 팀당 상한 −10%p, 순 조정 ±10%p.
- 측면 공격 효율이 중앙보다 높고(0.227 vs 0.106), 리시브 후 공격 효과·브레이크 성공률이 세트 승패를 가른다 [근거: 연구] → 이탈 선수가 이 두 지표에 얼마나 관여하는지가 핵심.
- (갱신 2026-10-19) 배구 조합 금지는 사용자 지시로 **해제** — KOVO(V-리그 남녀·KOVO컵)는 추천 다리 대상(가상 추천 모드 한정, 실투자 재개 전 종목별 적중률로 재판정). 기준선 산식은 `배구.md` 1-1절.

## 5. 라인업·포메이션 예측과 상성

**절차** (축구 기준, 다른 종목은 '누가 몇 분 뛰나'로 대체)
1. 결장 확정·등급 판정(0~4절).
2. **감독의 과거 비슷한 결장 2~3건**에서 대체 방식 확인 — 같은 포지션 대체(like-for-like)인가, 시스템 변경인가.
3. 직전 선발 XI(`match_inputs.py` INPUTS 블록) + 기자회견 + 뎁스로 **예상 XI·예상 포메이션**을 정하고 확신도(상/중/하) 기록. 예측 라인업 사이트 적중률은 선발 11명 중 87~90% [근거: 자체 보고], 결장 있는 경기는 더 낮다.
4. 공식 라인업(킥오프 60~75분 전) 발표 후 재확인 — 마감이 그 전인 블록은 예상 XI로만.
5. **상성은 포메이션 이름이 아니라 선수·역할 단위 비대칭만** 본다: 빠른 공격수 vs 높은 수비라인, 공중볼 강팀 vs 크로스 의존 팀, 세트피스(키커·장신 결장), 압박 강도 vs 빌드업 품질, 상대 약한 풀백 vs 윙어.

**가중치** (근거 강도에 맞춤)
| 항목 | 반영 | 근거 |
|---|---|---|
| 포메이션 이름 상성(3백 vs 4백 등) | **0, 많아야 ±1%p 동점 판정용** | 전력 통제 후 체계적 효과 약하거나 없음(Double ML 2.2만 경기; ANCOVA 0.1~0.3 xG 차이도 표본 희소) |
| 구체적 선수·역할 비대칭 | ±2%p 상한 | 방향은 통설, 크기 미검증 |
| 대체 선수 질(전력 저하) | 0~4절 공식으로 | 라인업 예측이 맞을 때만 |
| 야구 플래툰(좌우) | 타자 등급 안에서 | 타순 배열보다 효과 큼 [통설] |
