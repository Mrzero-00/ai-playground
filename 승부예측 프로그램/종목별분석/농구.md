# 농구 — 순수 분석 기법

## 1. 기준선
- 득실 마진(점수차/경기) 차이 + 홈 +2.5점 → 예상 점수차. 점수차 1점 ≈ 승률 3%p(점수차 표준편차 약 12점 기준).
  예: 예상 +4점 → 약 63%, +7점 → 약 72%.
- 시즌 초(10경기 이전)는 지난 시즌 마진과 섞는다. 컵 대회는 연습 성격이 있어 확신도 한 단계 낮춘다.

## 2. 조사 체크리스트
- [ ] **외국인 선수 2명 모두 출전 여부 — 경기 당일 감독 인터뷰·명단으로 확인 필수.** 2026-27 KBL은 외국인 2명 동시 출전이라 1명 결장이 **8~12%p**(이전 기준 5~8%p). 120회 정관장 라숀 토마스(무릎) 경기 당일 결장 → 베트맨 정관장 1.36→1.59(시장 약 65%→55%), 삼성 66-58 승. 전 경기에서 다쳤다가 악화된 선수는 '의문'이 아니라 결장 위험 높음으로 표시하고 구매 직전 확인
- [ ] 국내 주전 부상·복귀, '의문'은 0
- [ ] 연전(백투백)·휴식일 차(중2일 vs 중4일)
- [ ] 동기(컵 대회 토너먼트 여부, 순위 확정)
- [ ] 핸디캡·언더오버: 양팀 페이스(포제션), 최근 실점
- [ ] 이변 시나리오 + 성립 여부

## 3. 리그별 차이
| 리그 | 특이 변수 |
|---|---|
| KBL | 외국인 선수 의존도 최대, 컵 대회·시즌 초 로테이션, 승N패(1점차) 선택지 주의 |

## 4. 알려진 편향
- 120회: 시장 72.9 vs 순수 66.0(2경기) — 축구와 같은 '평평함' 의심, 표본 쌓이면 판정.

## 5. 회고 메모
- 120회 **정정(2026-10-10)**: 원인은 정보 누락 — 정관장 2옵션 외국인 라숀 토마스가 무릎 부상으로 당일 명단 제외(가스공사전에서 악화). 우리 조사는 '김종규만 결장'으로 놓쳤다. 다시 계산: 순수 60 − 외국인 1명 결장 10 ≈ 50% → 60% 미만이라 추천 제외 대상, 구매 직전 점검·배당 상승 경고(+0.23)로도 걸렀을 경기.
- 120회: 정관장 승(시장 67·순수 60) 실패 — 삼성 66-58. 삼성 김상식 신임 감독 체제 개막 2연승, 이규태 18점(우리는 '의문'으로 두고 결장 가정 안 함 — 맞는 처리). **[관찰] 개막 3경기 이내는 지난 시즌 순위(삼성 5년 꼴찌)가 낡은 정보** — 시장도 틀림. 개막 초 KBL은 확신도 한 단계 낮추고 조합 다리로 쓰지 않는 쪽을 후보로 둔다.

- **2026-10-12 사용자 지시: 농구는 조합 다리 금지(분석·기록만).** KBL 순수 방향 2/9·시장 3/6(119~120회). 해제 = 순수 방향 적중 70%+ (15경기+ 표본, 사용자 지시). `block_brief.py`가 농구 경기에 [후보] 대신 [농구보류]를 붙인다.
- 검증 기간(2026-10-12~): 모든 농구 경기 1차+2차 심층, 시장값만 기록 금지. 15경기 판정 — 70%+ 다리 재허용 검토 / 55% 미만 농구 전면 제외 / 그 사이 15경기 연장. 현재 집계 기점: 119~120회 2/9.
- 121회 10/12 모비스-DB: 순수 DB 68%·시장 66% → 모비스 승(DB 패). 구매 G(KT+KIA+DB 3만원) 이 다리 하나로 낙첨 — KIA ✓. 농구 순수 방향 누적 2/10.

## NBA 기준선 (2026-10-20 신설 — 124회 10/20 23:00 블록에서 정의)
> 그동안 NBA 절이 없어 분석가마다 방법이 달랐다. 아래로 고정한다.

1. 리그 기준값: 평균 효율 `LgRtg = 115.0`(2025-26), 평균 페이스 `99.0`.
2. 페이스추정 = (페이스_홈 + 페이스_원정) / 2
3. 득점_홈 = 페이스추정 × (ORtg_홈 + DRtg_원정 − LgRtg) / 100 **+ 홈이점 1.4**
   득점_원정 = 페이스추정 × (ORtg_원정 + DRtg_홈 − LgRtg) / 100 **− 1.4**
4. 점수차(홈−원정) = 정규분포, **σ 11.5** → 승/패·소수핸디캡 확률
   총득점 = 정규분포, 평균 = 득점_홈+득점_원정, **σ 17.5** → 언더오버 확률
5. **표본 수축(필수)**: 이번 시즌 표본이 적으면 직전 시즌 효율은 추정치일 뿐이다.
   - 개막 0~2경기: 승/패 `(값−50)×0.80+50`, 핸디캡·언더오버 `(값−50)×0.75+50`
   - 3~9경기: ×0.90 / 10경기+: 수축 없음
   - 로스터 변화에 따른 효율 조정은 **±3점 이내**(추측 금지).
6. 리그 평균을 결과 확률로 쓰지 않는다 — 위 분포 계산만으로 확률을 낸다.
7. [관찰] 페이스 수치를 못 구하면 99.0 대입이 불가피하지만, 그 경기는 언더오버 다리로 쓰지 않는다
   (124회 9534 샌안토니오-OKC 언더 232.5에서 페이스 미수집 → 내 65.7 vs 시장 50.7 로 15%p 벌어짐, 과신 판정으로 자동 배제됐다).
