# 배구 — 순수 분석 기법

## 1. 기준선
- 세트 득실률·점수 득실률 차이(최근 시즌) → 세트당 승률 p → 경기 승률(3선승): p 0.55 → 59%, 0.60 → 68%, 0.65 → 76%.
- 세트 핸디캡(±1.5)은 p로 3-0·3-1·3-2 분포를 계산해 판단한다.

### 1-1. 세트 득실률 → p 변환 공식 (2026-10-19 추가, 124회 9335 분석에서 정립)
팀별 **세트 득실률 R**(= 획득 세트 / 허용 세트, 출처: https://sports.daum.net/record/vl 또는 KOVO 기록실)에서 출발한다.
1. 팀 세트 승률 `s = R / (1 + R)`
2. 맞대결 세트 승률은 오즈비로 섞는다: `odds = (s홈/(1−s홈)) ÷ (s원정/(1−s원정))`, `p = odds / (1 + odds)`
3. 3선승 경기 승률 `P = p³(1 + 3q + 6q²)`, `q = 1−p`
4. 세트 스코어 분포: 3-0 `p³` / 3-1 `3p³q` / 3-2 `6p³q²` (원정은 p↔q)
   → 세트핸디캡 −1.5 충족 = 3-0 + 3-1, 세트 수 분포도 여기서 나온다.
- 예(124회 9335): 한국전력 R=1.075·KB손해보험 R=1.029 → s 0.518/0.507 → p 0.511 → 홈 52.0%/원정 48.0%, 세트핸디캡−1.5 충족 32.9%, 세트 수 3/4/5 = 25.0/37.5/37.5%.
- **세트 득실률은 승점 순위와 다르다**(124회: 승패 동률인데 한국전력 세트 1.075로 5위, KB 1.029로 3위). 순위가 아니라 세트 득실률을 써라.

### 1-2. 언더오버 세트 총점 기준 (2026-10-19 추가 — 분석가 오류 교정)
세트당 총점을 어림하지 말고 아래 범위를 쓴다. (124회 9335에서 1차 분석가가 세트당 48~55점을 가정해 오버를 74.9%로 20%p 과대 산출)
| 세트 수 | 총점 범위 | 비고 |
|---|---|---|
| 3세트(3-0) | 약 130~150 | 25점제 세트 = 승자 25 + 패자 15~23 ≈ 세트당 40~48점 |
| 4세트(3-1) | 약 170~200 | |
| 5세트(3-2) | 약 200~230 | 5세트만 15점제 = 승자 15 + 패자 8~13 ≈ 23~28점 |
세트 수 분포(1-1의 4)에 위 범위를 걸어 언더/오버를 낸다. 팀별 세트당 평균 득점 자료가 없으면 확신도를 '하'로 적는다.

### 1-3. KOVO컵은 중립 구장 (2026-10-19 추가)
KOVO컵(예: 2026 여수·NH농협컵)은 한 도시에서 몰아 치르므로 **'홈'은 베트맨 표기일 뿐 홈 이점이 없다** — 홈 보정 0이 기본값.

## 2. 조사 체크리스트
- [ ] 외국인 선수(아포짓)·아시아쿼터 출전, 세터 교체
- [ ] 대표팀 차출·복귀(국제대회 직후), 컵 대회 로테이션
- [ ] 연전·이동, 동기(순위결정전은 동기 약함 — 117회 인도-한국 제외 사례)
- [ ] 이변 시나리오 + 성립 여부

## 3. 리그별 차이
| 리그 | 특이 변수 |
|---|---|
| V리그·KOVO컵 | 컵 대회는 신인·백업 기용 많음, 외국인 선수 합류 시점. **중립 구장이라 홈 이점 0**(1-3절). 시즌 개막 전 컵은 직전 시즌 세트 득실률이 유일한 기준선인데 외국인·아시아쿼터가 바뀌어 신뢰도 중간 |
| 국제대회(아시안게임 등) | 순위결정전 동기, 1진/2진 파견 여부 |
