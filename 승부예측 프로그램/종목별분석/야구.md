# 야구 — 순수 분석 기법

## 1. 기준선
- 선발 매치업이 출발점: 양 선발의 최근 시즌 FIP/xFIP(없으면 ERA·WHIP), 최근 3경기, 상대 타선 상대 성적.
- 팀 득실차 기반 피타고리안 승률을 홈 +4%p로 보정한 값과 선발 매치업 값을 반반 섞는다.
- 선발 미발표 경기는 확신도 '낮음' + 제외 후보(119 KT-삼성 교훈: 확인 안 하면 제외 유지).
- **MLB 자동 기준선**: `python3 scripts/mlb_pitching.py [--date YYYY-MM-DD] [--detail] [--csv 경로]` — MLB Stats API로 확정 선발 FIP(40이닝 회귀)·최근 3선발, 팀별 최근 3일 불펜 투구 수와 연투·전날 30구+·마무리 3일 중 2회+ 경고를 뽑는다.
  - 기준선 홈 승% = 50 + 홈 4 + (원정FIP−홈FIP)×6 + 불펜 3일 투구 수 차 ×0.04(±3), 25~75% 제한. 시장 확률과 비교하는 출발점이며, 타선·구장·불펜데이는 체크리스트로 따로 본다.
- **KBO 자동 기준선**: `python3 scripts/kbo_pitching.py [--date YYYY-MM-DD] [--detail] [--csv 경로]` — KBO 공식 홈페이지(경기 목록·예고 선발 API, 박스스코어, 선수 기록 페이지)로 예고 선발 FIP(40이닝 회귀)·최근 3선발, 팀별 최근 3일 불펜 투구 수와 연투·전날 30구+·마무리 3일 중 2회+ 경고를 뽑는다. CSV 팀명은 베트맨 표기('LG 트윈스' 등).
  - 공식은 MLB와 같고 홈 +3%p만 다르다. FIP 상수는 KBO 팀 투수 합계로 매번 계산(2026 정규시즌 3.57, 리그 평균 4.67). 예고 선발은 보통 전날 오후에 뜨므로, 미발표면 확신도 '낮음'으로 두고 발표 뒤 다시 돌린다.

## 2. 조사 체크리스트
- [ ] 확정 선발(구단·KBO 공식 발표) — 오프너·불펜데이 여부
- [ ] **불펜 가용성**: 최근 3일 투구 수, 마무리·필승조 연투(순수 강점 변수 [중간], 116 KBO 3/3·119 SD-MIL)
- [ ] 순위 동기: 확정 팀의 주전 휴식, 포스트시즌 대비 선발 아끼기
- [ ] 라인업 결장(주전 타자), 출전 '의문'은 0으로
- [ ] 구장·바람·우천(돔 여부), 더블헤더
- [ ] 이변 시나리오 + 성립 여부

## 3. 리그별 차이
| 리그 | 특이 변수 |
|---|---|
| KBO | 시즌 막판 순위 확정 팀 주전 휴식·1군 첫 선발 기용, 외국인 선발 비중 큼, 잠실·라이온즈파크 구장 차이, 전반(5회) 선택지는 선발 매치업만으로 판단 |
| MLB 포스트시즌 | 탈락 위기 팀 불펜데이(119 CLE 7명 19K) → 약한 선발 감점 축소, 시리즈 흐름 서사는 근거로 쓰지 않음 |
| NPB 클라이맥스 시리즈 | 1st 스테이지 3전 2선승, 상위팀 홈·무승부 시 상위팀 진출 규정 → 하위팀이 공격적 운용, 에이스 등판 순서 |
