# 128회 심층 회고(5차) — 2026-10-29 · NBA 5 + MLS 5

신규 채점 10건(1136~1172). **10건 전부 분석이 들어가지 않은 행이었다** — MLS 5 는 pi 기준선 자동 채움, NBA 5 는
방향이 **통째로 비어 있었다**. 추천 다리 0건(128회 전 블록 '추천 없음'). 그래서 이번 회고의 본체는 경기 해석이
아니라 **표본이 왜 버려졌는가**이고, 그걸 코드로 막았다.

## 1. 이번 회고의 본론 — 채점된 경기의 20%가 방향 없이 버려지고 있었다

128회 채점 45경기 중 **9경기에 내 방향이 없었다**(NBA 5 · ACL2 4). 누적으로는 농구 23경기.
원인은 하나다 — **`baseline_fill.py` 가 축구 전용이었다.** 축구는 분석이 안 돼도 pi 기준선이 방향을 채우는데,
농구는 그런 자리가 없어 블록에서 빠지면 행이 빈 채로 채점만 됐다.

- 1136·1140·1144·1148 은 10/28 22:45 블록(22경기)에서 "NBA 4 기록만"으로 밀렸다.
- 1172 는 10/29 08:30 블록에서 "마감(08:30)이 분석 개시(08:29)와 겹쳐 미분석".

사용자 지시는 "표본을 버리지 않는다"이고, 목표 지표는 단일 경기 방향 적중률이다. 방향이 없는 행은
그 지표에 아예 들어가지 않는다 — 분석을 못 한 것이 **측정에서도 사라지는** 구조였다.

### 고친 것 — `nba_baseline.auto_baseline` + `baseline_fill` 농구 분기
`teamdb/nba` 박스스코어에서 팀별 ORtg·DRtg·페이스를 직접 재고(포제션 = FGA + 0.44·FTA − OREB + TOV)
경기 **전날까지의 경기만** 써서 기준선을 낸다(미래 누수 금지 — predict_engine 의 시간순 원칙과 같다).

**소급 검증 66경기 (채택 전 측정)**

| | 방향 적중 |
|---|---:|
| 자동 기준선 | 43/66 (65.2%) |
| 시장 | 46/65 (70.8%) |
| 내 심층 분석(같은 경기) | 39/59 (66.1%) |

- 방향이 **없던** 경기에 방향이 생긴다 — 그게 이 변경의 목적이다. 65%는 대조군으로 충분히 쓸 만하다.
- 부수적으로 드러난 것: **깊이=심층 58경기에서 자동 기준선 38/58(66%) = 내 심층 분석 38/58(66%)**.
  NBA 에서 뉴스·결장·라인업을 다 넣은 심층 분석이 뉴스를 전혀 안 보는 박스스코어 기준선과 구별되지 않는다.
  n=58 이라 단정하지 않지만, 블록마다 반복된 'NBA 과신' 관찰과 같은 방향을 가리킨다.

### 같이 고친 것 — 자동 기준선의 확률이 거짓말을 하고 있었다
첫 구현(SD 11.5 × 수축 0.90)은 **말한 평균 74.0% vs 실제 65.2% = −8.9p** 였다.
원인은 계수가 아니라 **전제**다. SD_MARGIN 11.5 는 '레이팅을 정확히 안다'는 가정의 경기별 마진 산포인데,
여기 레이팅은 이번 시즌 6~9경기로 **직접 추정한 값**이고 뉴스도 안 본다. 두 오차가 더 얹힌다.

    SD_eff = √( SD_MARGIN² + AUTO_MODEL_SD² + 2·SD_MARGIN²/n )

`AUTO_MODEL_SD = 18.0` 으로 격차가 **−8.9p → −1.6p**(Brier 0.2356 → 0.2215). 정확히 0 이 되는 값은 22 지만
n=66 에 스칼라를 꽉 맞추지 않고 보수적으로 18 에 둔다. 재측정은 `python3 scripts/nba_baseline.py --calib`(120경기마다).
**방향 적중률은 SD·수축에 불변이다**(65.2% 고정) — 이 변경이 고치는 것은 '내가 말한 확률의 정직함'뿐이고,
판정 지표를 건드리지 않는다. 분석가가 직전시즌 레이팅·결장 보정을 직접 넣는 CLI 경로는 그대로 둔다.

채운 결과(128회): 1136 홈 72.6 ✗ · 1140 54.8 ✓(기권 구간) · 1144 85.1 ✓ · 1148 59.2 ✗ · 1172 65.6 ✓ = **3/5**(시장 4/5).

## 4. 고친 것 (도구)
1. **`nba_baseline.team_ratings` / `auto_baseline`** — teamdb 박스스코어로 팀 레이팅을 재고(as_of 이전 경기만) 팀명만으로 기준선을 낸다. 최소 3경기.
2. **`nba_baseline` SD 분해 + `--calib`** — `AUTO_MODEL_SD=18.0`(실측). `--calib` 로 언제든 재측정하고 후보값을 본다. 분석가 CLI 경로는 불변.
3. **`baseline_fill.py` 농구 분기 + `--refresh`** — NBA 행을 깊이=기준선으로 채우고, 1·2순위 차 10%p 미만은 확신도 '기권'. 꼬리표를 항상 붙여 계수를 고친 뒤 소급 재계산이 되게 했다(128회 1172 가 블록 메모 때문에 혼자 옛 값으로 남았던 사고). 깊이=심층·가벼움 행은 `--refresh` 라도 덮지 않는다.
4. **`lineup_grade.py`** — 예상XI 가 배열·dict 인 수집 JSON 에서 죽던 결함.

## 5. 점검표 변동
- 추가(1회): **NBA 자동 기준선이 시장과 방향이 갈리면 기준선을 결론으로 두지 말고 심층 분석 후보로 올린다**(1148. 실측 22건 기준선 9/22 vs 시장 13/22, 2SE ±21%p 라 아직 규칙 아님).
- 추가(1회): **축구 기준선이 1·2순위 차 10%p 미만이면 적중해도 '근거대로'로 세지 않는다**(1160·1164·1168 — 셋 다 슈팅 열세·대등에서 1골차 승).
- 상위 변동 없음(G1 10%p 10회 · 농구 시장기준선 5회 · G5 의심 4회).

## 6. 바꾸지 않은 것과 이유
- **요인 보정 0/8**: factor_fit 이 −2.4p, 부호 안정성 최고 72.8%. 표본이 251로 늘었는데도 관문을 넘는 유형이 없다.
- **G1 10%p 문턱**: calib_report 가 4회 연속 '차 3~6p 가 0~3p 보다 낮음' 역전을 보고하지만 전부 |z|<2 다. 이번 1140(차 9.6p·기권)이 맞았지만 전반 10점 열세 역전이라 문턱 근거가 되지 못한다.
- **코어 추천 규칙**: 128회 코어 다리 0건이라 재측정 대상이 없다.
- **결장 weight 0**: 이번 10건에 결장이 방향을 바꾼 사례 없음(전부 기준선 행이라 결장 입력 자체가 없다).
