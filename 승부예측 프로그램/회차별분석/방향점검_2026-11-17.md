# 주간 방향 점검 — 2026-11-17

회고는 틀 안에서 가중치를 고친다. 이 점검은 **틀 자체가 맞는지**를 묻는다.
판정은 방향 적중률 하나로 한다. 회수율·RPS·Brier 는 보조 진단으로만 적는다.

## 1. 모델 계층 상한 — 지금 쓰는 기준선보다 나은 틀이 있는가
```

----------------------------------------
1 홈 고정                 3130      43.0%

> 읽는 법: 어떤 모델도 시장을 못 넘으면, **과거 결과만으로는 더 못 간다**는 뜻이다.
> 그때 개선은 결과표 밖 정보(선발·부상·휴식·동기)에서만 나온다.
> 반대로 어떤 모델이 현재 기준선보다 유의하게 높으면 **기준선 교체**가 답이다(조정).

## 2. 요인이 정보인가 잡음인가 — 수집한 사실이 확률로 제대로 바뀌는가
```

계수는 '내가 매긴 %p 1점이 결과 로그오즈를 얼마나 움직였나'다.
두 관문을 다 넘지 못한 유형은 수집·기록만 하고 확률은 사전확률 그대로 둔다 — 보정 0 이 기본값이다.
'역부호'는 반대로 적용하고 있다는 뜻이지만, 뒤집어 쓰지 않는다(표본이 적어 부호만 바꾸면 과적합이다).

> 유형별 역부호가 많으면 가중치 조정으로는 부족하고 환산 규칙 자체를 다시 세워야 한다(전환).

근거:
- **모델 계층(§1)**: 11/02 와 같다 — Elo 51.6% · 득점 레이팅 51.8% · 시장 53.4%. 과거 결과만으로는 더 못 간다. 이번 주에 국가대표 Elo 의 친선 전용 상수를 따로 시험했으나 방향 58.6% → 58.6%(시험 1,647경기)로 기각.
- **요인(§2)**: 0/5 유형 채택. 시장만 60.9% vs 시장+요인 56.5%(−4.3p, 시험 69경기). 보정 0 이 여전히 맞다.
- **개입(§3)**: 본 지표 ★ 11-02 이후 85경기(이번 주에 국가대표·NBA 재현을 붙여 27 → 85) — 내 67.1%, 기준선 대비 **−2.4p ±4.7**, 개입 4건. 지난 점검의 '+6.9p' 는 학습 안 된 모델과의 차이였음이 11/11 에 드러났고, 제대로 잰 값은 0 근처다. 심층 분석이 방향을 바꾸지 못한다는 결론 유지.
- **정합(§4)**: 분석 행 1순위는 종목·리그별로 유의한 편향 없음(축구 −0.6p, 심층 +1.5p). 유의한 것은 '무 +2.4p 과대'(n=1,342, z=−2.1)와 '구회차' 행뿐.
- **추천(전진 시험)**: 선별 통과 26경기 84.6% vs 탈락 15경기 53.3%(z=+2.13), 합계 1.8~2.2배 조합 4연속 적중, 2폴더 누적 8/19(회수 94.2%). 표본이 작아 판정은 약속(통과 60경기)까지 미룬다.
