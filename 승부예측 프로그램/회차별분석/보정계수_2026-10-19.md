# 순수 확률 보정 계수 (2026-10-19)

원본 = 순수 확률 그대로. 보정 = 로짓에 온도 T 를 곱하고 홈·무 편향을 더한 뒤 정규화. 5-fold 교차검증 RPS 가 원본보다 낮을 때만 채택.
표본 적으면 n/(n+100) 만큼만 적용(T→1, b→0 쪽으로 축소).

| 종목 | n | T | 홈 편향 | 무 편향 | 원본 RPS | 보정 RPS(학습) | 원본 CV | 보정 CV | 채택 |
|---|---|---|---|---|---|---|---|---|---|
| 축구 | 294 | 1.63→1.47 | +0.25→+0.19 | +0.06→+0.04 | 0.2023 | 0.1935 | 0.2023 | 0.1976 | 예 |
| 야구 | 31 | 0.82→0.96 | -0.10→-0.02 | - | 0.2459 | 0.2450 | 0.2459 | 0.2653 | 아니오 |
| 농구 | 14 | - | - | - | - | - | - | - | 표본 부족 |
| 배구 | 1 | - | - | - | - | - | - | - | 표본 부족 |
