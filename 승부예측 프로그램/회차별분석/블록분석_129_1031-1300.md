## 이 블록이 드러낸 것 — gap 은 분석하지 않은 행에서만 나온다
코어 규칙은 **갈림(−15 ≤ 내−시장 ≤ −5)** 을 요구하는데, 2026-10-26 구조 전환은 **사전확률 = 시장 · 기본 보정 0**
이다(요인 8종 weight 전부 0.0). 그래서 **분석을 제대로 할수록 gap 이 0 으로 수렴한다.** 이 블록에서 유일하게
밴드에 든 1449 는 **분석하지 않은 pi 기준선 행**이다.

구조 전환 이후(10/26~) 전수로 재 봤다:

**분석이 gap 을 절반 가까이 줄인다**(평균 |gap| 4.48 → 2.91, 밴드 진입률 27.7% → 17.9%).
추천 규칙은 갈림에 보상을 주는데 분석 절차는 갈림을 없애도록 설계돼 있다 — 둘이 서로를 상쇄한다.
