# 적중 예상도 모델 (2026-10-22)

예상 결과 = 순수 1순위. 적중 예상도 = 그 1순위가 맞을 확률(로지스틱, 5-fold CV). 추천 문턱 60%, 70% 구간이 실제 70%를 넘기면 70%로.

## 축구 (n=320)

계수: 상수 -0.33, 순수1순위x10 -0.20, 1-2순위차x10 +0.51, 홈픽 +0.36, 무픽 +0.18, 보정1순위일치 +0.37

| 적중 예상도(CV) | 다리 | 실제 적중 |
|---|---|---|
| 0~50% | 103 | 41 (40%) |
| 50~60% | 75 | 45 (60%) |
| 60~65% | 35 | 20 (57%) |
| 65~70% | 45 | 29 (64%) |
| 70~75% | 21 | 16 (76%) |
| 75~100% | 41 | 32 (78%) |

| 추천 문턱 | 다리 | 적중 |
|---|---|---|
| 60%+ | 142 | 97 (68%) |
| 65%+ | 107 | 77 (72%) |
| 70%+ | 62 | 48 (77%) |

70% 문턱 승격 조건(20다리+·실제 70%+): 충족

- 야구: 32경기, 표본 부족(40 미만) → 보정 1순위 확률을 적중 예상도로 대체
- 농구: 30경기, 표본 부족(40 미만) → 보정 1순위 확률을 적중 예상도로 대체
- 배구: 6경기, 표본 부족(40 미만) → 보정 1순위 확률을 적중 예상도로 대체
