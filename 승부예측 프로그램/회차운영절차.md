# 회차 운영 절차 — 전체 경기 분석·기록·회고 (사용자 지시 2026-10-07)

> **회차마다 모든 경기를 분석하고, 모든 경기를 기록하고, 회차가 끝나면 구매 여부와 상관없이 모든 경기를 회고한다.**
> 목적: 분석이 맞았는지(성공 여부)를 경기 수백 개 단위로 검증하고, 그 결과로 분석 스킬을 고친다.
> 이 파일은 저장소에 있으므로 어느 PC에서든 `git pull` 후 이 순서대로 진행한다.

## 기록 파일 (모두 git에 올린다)
| 파일 | 단위 | 내용 |
|---|---|---|
| `전체경기기록.csv` | 경기 1행 | 순수 분석 확률(배당 미참조)·확신도·핵심근거·뉴스위험·제외 / 시장 확률(Pinnacle) / 베트맨 배당 / 추천·구매 / 결과·적중 |
| `data/스캔기록.csv` | 선택지 1행 | 핸디캡·언더오버 포함 전체 선택지의 공정확률·기대값 (`odds_scan.py --log`, tracker) |
| `예측기록.csv` | 추천 선택지 | 추천·구매한 선택지 상세 |
| `구매기록.csv` | 티켓 1행 | 구매 티켓·배당·결과·회수 |
| `회차별분석/` | 문서 | 사전 분석, 추천, 전체 회고 |

## 1. 회차 시작 (대진 공개 직후, 판매 전이어도 됨)
1. `python3 scripts/round_log.py init <회차>` — 대진 전 경기를 `전체경기기록.csv`에 등록.
2. **모든 경기**를 배당 없이 조사한다(경기 1~2개당 조사 에이전트 병렬, `분석방법론.md`·스킬의 변수 목록).
   - **종목별 기준선·체크리스트는 `종목별분석/<종목>.md`** (조사 에이전트 프롬프트에 해당 종목 체크리스트와 리그 절을 붙인다).
   - 야구: 선발·불펜 소모·순위 동기. 축구: 전력 차 숫자 기준선(xG·득실) → 결장·로테이션·순위·컵 대회 여부. 농구: 외국인 선수·연전.
   - 경기마다 순수 확률(승/무/패), 확신도(높음·중간·낮음), 핵심근거 한 줄, 뉴스위험 한 줄, 제외 여부.
3. 결과를 CSV(열: 홈,원정,순수_승,순수_무,순수_패,확신도,핵심근거,뉴스위험,제외,**변수**)로 만들어 `round_log.py pure <회차> <파일>`로 입력.
4. 사전 분석 문서: `회차별분석/YYYY-MM-DD_프로토<회차>_사전분석.md`. 제외 경기는 `data/exclude.json`에도 넣는다.

## 2. 판매 중 (배당 공개 후 ~ 킥오프)
1. `python3 scripts/round_log.py market <회차>` — 경기별 시장 확률·베트맨 배당 기록. **킥오프 1~3시간 전에 다시 돌려 마감에 가까운 값으로 덮어쓴다.**
2. `python3 scripts/odds_scan.py --best --log` — 전체 선택지 기록 + 추천 후보.
3. 순수 분석과 시장이 10%p 이상 다른 경기를 표시하고 근거를 다시 확인한다(시장이 더 정확했던 백테스트 결과를 기억).
4. 추천 표는 `pick_table.py --round N --save "제목=번호:선택,..." --buy "제목=금액"`, 뺀 선택지는 `--skip "번호:선택=이유"`로 `추천기록.csv`에 남긴다(사용자에게는 설명하지 않고 회고 때 채점 — 리그별 성적표·기권 정확도). 경기 단위 메모는 `전체경기기록.csv` 비고 `추천제외: 이유`.
5. 추천(수익 기준 기대값 1.02+ / 사용자 방식: 배당 1.3+ 적중 최대 조합)과 구매를 `전체경기기록.csv`의 추천·구매 열, `구매기록.csv`에 남긴다.
6. **조건부 제외 경기**(라인업·선발 확인 후 해제하기로 한 경기)는 킥오프 2시간 전에 라인업을 실제로 확인하고 `data/exclude.json`에서 빼거나 유지한 뒤 재스캔한다. 확인을 건너뛰면 제외 유지로 간주한다(119회 KT-삼성 교훈, 2026-10-08).
7. 같은 대진이 회차 안에 두 번 있으면(MLB 시리즈 G3·G4) `round_log.py market/results`가 (홈,원정) 이름으로 매칭해 앞 경기를 덮어쓴다. 번호 매칭으로 고치기 전까지는 먼저 끝난 경기 행을 수동 보존한다.

## 3. 회차 종료 후 — 전체 회고 (구매 여부 무관)
1. `python3 scripts/round_log.py results <회차>` — 베트맨 공식 결과로 모든 경기 채점. 베트맨에 아직 안 올라온 경기는 검색으로 확인해 직접 채운다.
2. `python3 scripts/tracker.py results --round <회차>` → `report` → `clv` — 전체 선택지 채점·CLV.
3. `python3 scripts/round_log.py review <회차>` — `회차별분석/YYYY-MM-DD_프로토<회차>_전체회고.md` 생성:
   - 순수 분석 vs 시장: 1순위 적중, RPS(전체·종목별·확신도별·제외 경기)
   - 둘이 갈린 경기에서 누가 맞았나
   - 틀린 경기 전체 목록 → 원인 분류(정보 누락 / 가중치 오판 / 무승부 과소평가 / 순수 이변)를 채운다
4. 분석 스킬 개선:
   - 2~3회 반복된 패턴만 `분석규칙.md`에 규칙으로(근거 회차·신뢰도). 한 번은 [관찰].
   - 순수 분석이 시장보다 RPS가 좋은 영역(종목·리그·확신도)이 생기면 그 영역의 가중치를 올린다. 나쁜 영역은 시장 기준으로 되돌린다.
   - 팀·선수 특성은 `팀노트/`, `선수노트/`.
5. 보고: 적중과 수익(ROI)을 분리해서 말한다.

## 판정 기준
- 비교는 같은 경기 집합에서만(순수·시장 둘 다 있는 경기).
- 표본 100경기 미만의 차이는 우연일 수 있다고 함께 적는다.
