# 선물(공매도·레버리지) — 사전 등록

2026-11-17 고정. BACKTEST.md 의 '공매도·레버리지 — 보류'는 업비트 현물 가격으로 선물을 흉내 냈다. 여기서는 바이낸스 USDT 무기한 실제 가격·실제 펀딩비로 다시 보고, 같은 방식들을 모의 매매로 병행한다.
실제 돈은 현물 실전 검증(CLAUDE.md 실전 순서) 뒤에만 검토한다.

## 방식 (BACKTEST.md 와 같은 4개, 새로 고르지 않는다)
e = 앙상블 비중(SMA 20·50·100·200 위에 있는 수 ÷ 4, 바이낸스 선물 일봉 종가 기준)

| 이름 | 포지션 (자본 대비 명목) |
|---|---|
| F0 롱만 | e (현물 봇과 같은 비중을 선물로) |
| F1 대칭 | 2e − 1 (−1 ~ +1) |
| F2 롱+전부 아래면 숏 | e > 0 이면 e, e = 0 이면 −1 |
| F3 2배 롱 | 2e |

## 백테스트 (`scripts/futures_backtest.py`)
- 가격: 바이낸스 BTCUSDT·ETHUSDT 무기한 일봉(00:00 UTC = 09:00 KST 마감). USDT 기준 수익(환율 효과 제외).
- 신호 t 종가 → t+1 수익. 마켓 균등 평균.
- 비용: 거래 편도 0.10%(테이커 0.05% + 슬리피지 0.05%), 0.25% 견고성.
- 펀딩: t+1 에 붙은 실제 펀딩비 합 × 포지션 (롱은 양수일 때 낸다, 숏은 받는다).
- 청산: 그날 저가·고가로 포지션 손실이 자본의 99.5% 이상이면 그 마켓 자본 0 (격리 마진, 유지 증거금 0.5% 근사).
- 표본 외 2023-01~ 로 판단, 전체(2020~)는 참고.

## 모의 매매 (`scripts/paper_futures.py`)
- 4개 방식 모두 동시에, 방식마다 10,000 USDT (BTC·ETH 각 5,000). 결과를 보고 하나를 고르지 않는다.
- 매일 09:15 KST. 실시간 선물 호가창을 먹는 시장가 체결 계산, 수수료 0.05%.
- 지난 실행 이후 실제 펀딩 이벤트를 펀딩 시점 마크가격 × 수량으로 정산.
- 지난 실행 이후 1시간봉 저가·고가로 청산 여부 확인.

## 실전 검토 조건 (2027-02-17 이후, 모두 만족해야)
1. 현물 실전이 3개월 이상 문제없이 돌았다.
2. 그 방식이 백테스트 표본 외에서 F0 보다 샤프가 높고 MDD 가 5%p 넘게 나쁘지 않다.
3. 모의에서도 F0 보다 나쁘지 않고 펀딩·슬리피지가 백테스트 가정 안이다.
4. 해외 거래소 이용 규제·출금 위험을 사용자가 직접 확인했다.

## 결과 (2026-11-17, `scripts/futures_backtest.py`)

USDT 기준, 바이낸스 무기한 실제 가격·펀딩. 청산은 4개 방식 모두 0회.

| 방식 | 표본 외 2023~ 연복리 / 샤프 / MDD | 0.25% 비용 샤프 | 전체 2020-06~ 연복리 / 샤프 / MDD | 연 펀딩 부담 |
|---|---|---|---|---|
| F0 롱만 | +25.9% / 0.86 / -32.5% | 0.77 | +35.0% / 0.94 / -48.9% | 5.5% |
| F1 대칭 | +19.7% / 0.65 / -41.2% | 0.49 | +25.6% / 0.71 / -53.7% | 3.7% |
| F2 롱+전부 아래면 숏 | +29.6% / 0.83 / -36.9% | 0.70 | +32.1% / 0.80 / -66.0% | 4.9% |
| F3 2배 롱 | +42.3% / 0.86 / -57.2% | 0.77 | +54.3% / 0.94 / -79.3% | 10.9% |
| (참고) 업비트 현물 앙상블 | +43% / 1.43 / -26% | 1.34 | | 0 |

연도별: F1·F2 는 2022(0%·-17%)와 2026(+40%) 하락장에서 낫고, 2021·2023·2024 상승장에서 크게 뒤진다.

판정: 실전 검토 조건 2(F0 보다 샤프 높고 MDD 5%p 이내)를 넘는 방식이 없다. 숏·레버리지는 위험 대비 수익을 늘리지 못한다.
더 큰 발견은 F0 자체가 업비트 현물보다 훨씬 나쁘다는 것:
- 롱일 때 펀딩비가 연 5.5% 를 깎는다.
- 같은 규칙이라도 달러 가격 신호와 원화 가격 신호가 16~22% 날짜에서 다르고, 비용 전 추세 수익이 달러 쪽이 낮다(BTC 연 39% vs 44%).
→ 이 전략은 업비트 현물(원화)로 하는 것이 맞다. 모의 매매는 실제 펀딩·체결 기록용으로만 돌린다.

백테스트 첫 실행에서 F2 가 워밍업 구간(이평 계산 전)을 '전부 아래'로 읽어 숏을 잡는 버그가 있어 고쳤다(판정 전).
