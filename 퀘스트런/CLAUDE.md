# 퀘스트런 프로젝트 가이드

## 제품 목표

- 실제 달리기를 캐릭터 성장, 퀘스트, 전투, 수집으로 연결한다.
- 속도 경쟁보다 거리와 꾸준함을 보상한다.
- 달리는 중에는 조작을 최소화하고 전투와 보상 확인은 러닝 종료 후 제공한다.

## 기술

- React Native
- Granite
- Apps in Toss React Native SDK
- TypeScript

## 제품 규칙

- 지역 업적 보상은 꾸미기 전용이며 전투 능력치를 올리지 않는다.
- 지구력은 일일 퀘스트 연속 달성 마일스톤으로만 증가한다.
- 숨은 업적은 달성 전 정확한 조건을 공개하지 않는다.
- 위치 원본 데이터는 필요한 범위보다 오래 보관하지 않는다.
- MVP에서는 속도에 따른 추가 보상을 제공하지 않는다.

## 구현 규칙

- 게임 계산은 `src/domain`의 순수 함수로 관리하고 테스트한다.
- 화면 문구는 한국어를 기본으로 한다.
- 앱인토스 SDK에 없는 네이티브 모듈을 임의로 추가하지 않는다.
- 접근성 라벨과 충분한 터치 영역을 유지한다.
