# 탐정 000

매일 한 편의 사건을 읽고, 용의자 네 명의 진술과 이미지 증거를 조합해 범인을 추리하는 앱인토스 미니앱입니다.

오늘의 사건은 무료로 제공되며 정답은 다음 날 공개됩니다. 사건을 끝까지 푼 사용자만 사건에 별점을 남길 수 있고, 공식 사건의 추리 결과는 개인의 `추리력`으로 기록되어 공유할 수 있습니다.
