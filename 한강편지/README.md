# 한강에서 온 편지 MVP

한강공원에 무작위로 도착한 익명 편지를 현장에서 발견하고, 최초 한 사람만 획득하는 앱인토스 비게임 미니앱입니다.

## 구현 범위

- 앱인토스 WebView SDK 2.x 설정과 비게임 내비게이션
- `getAnonymousKey` 기반 익명 사용자 식별, 일반 브라우저용 로컬 식별키 폴백
- 텍스트 편지 작성과 연락처·URL·만남 유도 패턴 차단
- 1~6시간 표류 후 활성 공원 중 하나로 무작위 도착
- 공원명과 미획득 편지 개수만 노출하는 일러스트형 한강 지도
- 서버에만 보관되는 안전 탐색 좌표와 40m 기본 획득 반경
- 앱인토스 위치 API와 브라우저 위치 API 폴백
- 실시간 카메라 미리보기와 앱인토스 `openCamera` 촬영 폴백
- 2분 유효 발견 증표와 데이터베이스 트랜잭션 기반 1인 독점 획득
- 공원당 24시간 미획득 시 다른 공원 재표류, 최대 3개 공원 후 만료
- 띄운 편지·주운 편지 보관함, 신고 즉시 숨김
- AES-256-GCM 편지 본문 암호화와 원본 사용자 식별키 비저장
- 콘텐츠, 표류, 독점 획득 도메인 자동 테스트

MVP에서는 답장, 댓글, 공개 피드, 사용자 검색을 제공하지 않습니다.

## 프로젝트 구조

```text
한강편지/
├── apps/
│   ├── api/                 # Node.js API, SQLite 영속 데이터와 도메인 규칙
│   └── web/                 # React, Vite, 앱인토스 WebView 미니앱
├── docs/product/            # 서비스 기획안, PRD, 개발·운영 요구사항
├── .env.example
├── package.json
└── pnpm-workspace.yaml
```

## 로컬 실행

Node.js 22와 pnpm 10 이상을 사용합니다.

```bash
cp .env.example .env
pnpm install
pnpm dev
```

- 웹: `http://localhost:5173`
- API 상태 확인: `http://localhost:4100/health`

일반 브라우저에서는 실제 공원 위치 판정을 통과할 수 없으므로 탐색 화면 아래의 `로컬 체험 위치 사용` 버튼으로 전체 획득 흐름을 확인할 수 있습니다. 이 버튼은 개발 빌드에만 노출되고, 운영 API는 `ALLOW_SIMULATED_LOCATION=false`로 실행해야 합니다.

## 검증

```bash
pnpm check
pnpm ait:build
```

`pnpm check`는 API·웹 타입 검사, 도메인 테스트, 프로덕션 빌드를 순서대로 실행합니다.

## 앱인토스 연결

1. 앱인토스 콘솔에 비게임 미니앱을 등록합니다.
2. `apps/web/granite.config.ts`의 `appName`, `displayName`, `icon`을 콘솔 값과 일치시킵니다.
3. 위치와 카메라 권한 사용 목적을 콘솔·서비스 화면·개인정보 처리방침에 동일하게 기재합니다.
4. 최신 샌드박스 앱에서 권한 허용·거부·영구 거부, 백그라운드 전환, 두 기기 동시 획득을 검증합니다.
5. `pnpm ait:build`로 생성된 번들을 콘솔에 업로드합니다.

## 운영 배포 전 교체 항목

현재 API는 별도 인프라 없이 MVP를 실행할 수 있도록 Node.js 내장 SQLite를 사용합니다. 공개 베타 전에는 다음을 교체하거나 확정해야 합니다.

- PostgreSQL/PostGIS와 관리형 백업·복구 체계
- 앱인토스 익명키 서버 검증용 mTLS 인증서
- KMS 기반 `LETTER_ENCRYPTION_KEY` 보관과 키 교체 절차
- 공원 관리 주체와 협의한 실제 안전 탐색 다각형 및 제외 영역
- 자동 검수 공급사와 운영자 검수 콘솔
- 위치기반서비스 신고·약관·개인정보 처리방침 법률 검토
- API 도메인, TLS, WAF, 속도 제한, 모니터링과 장애 알림

자세한 정책은 [PRD](docs/product/PRD.md)와 [개발요구사항 정의서](docs/product/개발요구사항_정의서.md)를 확인하세요.
