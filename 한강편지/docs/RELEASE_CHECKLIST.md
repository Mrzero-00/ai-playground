# 공개 MVP 출시 체크리스트

## 앱인토스

- [ ] 콘솔 `appName`, 표시 이름, 아이콘과 `granite.config.ts` 일치
- [ ] WebView SDK 2.x 최신 안정 버전과 최신 샌드박스 앱 사용
- [ ] 비게임 내비게이션, 라이트 모드, 뒤로가기·종료 동작 확인
- [ ] 위치·카메라 권한 목적 안내와 거부·영구 거부 폴백 확인
- [ ] Android·iOS 실제 토스 앱 QR 테스트
- [ ] `ait build` 결과 100MB 미만 확인

## 위치와 현장 안전

- [ ] 최초 5개 공원의 실제 보행 가능 안전 탐색 영역 현장 답사
- [ ] 수변 난간, 차도, 자전거도로, 계단, 급경사, 공사·행사 구역 제외
- [ ] 야간·기상·행사·침수 상태별 공원 즉시 중지 기능 연결
- [ ] 운영팀이 실제 목표 좌표를 일반 조회하지 못하도록 역할 분리
- [ ] 20개 이상 무작위 좌표 블라인드 도보 테스트

## 개인정보·법률

- [ ] 위치기반서비스사업 신고 대상과 이용약관 범위 전문 검토
- [ ] 위치정보·개인정보 처리 목적, 항목, 보유 기간, 파기 절차 확정
- [ ] 원본 위치가 로그·분석·오류 도구에 남지 않는지 자동 검사
- [ ] 앱인토스 익명 사용자키 검증 API와 mTLS 적용
- [ ] 탈퇴·삭제 요청과 법정 보존 예외 처리 검증

## 콘텐츠·운영

- [ ] 자동 검수와 사람 검수 공급자·SLA 확정
- [ ] 자해·성착취·폭력·불법 고위험 신고 즉시 숨김과 대응 절차 훈련
- [ ] 반복 위반 제재, 이의 신청, 감사 로그 구현
- [ ] 공원별 편지 재고와 발송·획득 제한 운영값 확정
- [ ] 고객지원 문의 유형과 실제 좌표 비공개 답변 원칙 교육

## 기술

- [ ] SQLite를 PostgreSQL/PostGIS로 교체하고 마이그레이션 검증
- [ ] 동시 획득 100건에서 정확히 1건만 성공하는 부하 테스트
- [ ] TLS, WAF, 요청 속도 제한, 비밀 관리, 백업·복구 적용
- [ ] 스케줄러 지연, 공원 재고 0·상한, 신고 SLA 알림 연결
- [ ] 프로덕션에서 `ALLOW_SIMULATED_LOCATION=false` 확인
