# 한강에서 온 편지 — 서비스 기획안

문서 버전: v0.1
작성 기준일: 2026-09-02
가명: 한강에서 온 편지

## 1. 기획 요약

“한강에서 온 편지”는 누군가 익명으로 띄운 편지가 가상의 한강 물길을 따라 흐른 뒤, 실제 한강공원의 안전한 지점에 도착하면 다른 사용자가 현장에서 발견해 읽는 위치 기반 감성 서비스다.

서비스의 핵심은 익명 편지 자체가 아니라 다음 세 감정의 연결이다.

1. 내 마음을 어딘가로 흘려보내는 해방감
2. 편지가 어디에 닿을지 기다리는 기대감
3. 실제 장소에서 낯선 사람의 마음을 발견하는 우연성

MVP는 정교한 증강현실 기술보다 “현장에 가야만 얻을 수 있다”는 규칙과 발견 연출을 우선 검증한다.

## 2. 배경과 문제 정의

### 2.1 사용자 문제

- 일상에서 가볍게 속마음을 꺼낼 수 있는 안전한 공간이 부족하다.
- 기존 익명 커뮤니티는 즉각적인 반응과 갈등 중심으로 흐르기 쉽다.
- 산책이나 한강 방문은 반복되지만 방문 자체에 새로운 목적과 이야기가 부족하다.
- 위치 기반 서비스는 보상과 경쟁에 치우쳐 감성적 경험이 상대적으로 드물다.

### 2.2 기회

한강은 서울 시민에게 이동 경로, 휴식 공간, 데이트 장소이면서 동시에 “흘려보냄”과 “도착”의 서사를 자연스럽게 담을 수 있는 상징적 장소다. 디지털 편지에 실제 공간·시간·우연성을 결합하면 기존 익명 커뮤니티와 다른 느린 소통 경험을 만들 수 있다.

### 2.3 해결 가설

사용자가 작성한 편지가 일정 시간 표류하고, 다른 사용자가 한강공원에서만 획득하도록 만들면 다음 효과가 발생할 것이다.

- 발신자는 즉시 반응을 요구하지 않고 부담 없이 감정을 표현한다.
- 수신자는 산책에 작은 목적을 얻고 발견 자체를 보상으로 느낀다.
- 편지는 공개 피드가 아닌 1:1 우연한 전달이 되어 비교와 과잉 노출을 줄인다.

## 3. 서비스 정의

### 3.1 한 문장 소개

한강을 따라 흘러온 익명의 편지를 공원에서 발견하고, 나의 편지도 물결 위에 보내는 위치 기반 편지 서비스.

### 3.2 핵심 가치 제안

| 대상 | 제공 가치 |
|---|---|
| 편지를 보내는 사람 | 이름을 드러내지 않고 마음을 안전하게 흘려보내는 경험 |
| 편지를 찾는 사람 | 산책 중 예상하지 못한 타인의 이야기를 발견하는 경험 |
| 한강 방문자 | 평범한 방문을 작은 탐험과 기억으로 바꾸는 동기 |
| 운영자 | 위치·콘텐츠·재방문이 결합된 차별화된 로컬 서비스 포맷 |

### 3.3 포지셔닝

익명 커뮤니티가 아니라 “느린 1:1 전달 서비스”로 정의한다. 공개 댓글, 팔로우, 인기 순위, 무제한 대화를 배제해 경쟁과 자극 대신 우연성과 진정성을 지킨다.

## 4. 목표 사용자

### 4.1 1차 타깃

- 서울 거주 또는 한강공원을 자주 방문하는 20~39세
- 산책·러닝·데이트 중 가벼운 경험을 찾는 사용자
- 일기, 편지, 감성 콘텐츠에 친숙하지만 공개 SNS 노출은 부담스러운 사용자

### 4.2 대표 페르소나

#### 페르소나 A — 마음을 흘려보내는 직장인

- 상황: 퇴근 후 감정은 남지만 지인에게 말하기는 부담스럽다.
- 필요: 평가받지 않고 짧게 마음을 정리하고 싶다.
- 성공 순간: “누군가 읽었다”는 사실만으로 위안을 얻는다.

#### 페르소나 B — 산책에 이유가 필요한 방문자

- 상황: 주말마다 한강을 걷지만 매번 비슷하게 느껴진다.
- 필요: 가까운 거리 안에서 수행할 작은 목적이 필요하다.
- 성공 순간: 현장에서 편지를 찾고 예상하지 못한 이야기를 읽는다.

#### 페르소나 C — 함께할 가벼운 경험을 찾는 커플·친구

- 상황: 한강에서 할 수 있는 짧고 새로운 활동을 찾는다.
- 필요: 설치 부담 없이 10~20분 안에 체험할 콘텐츠가 필요하다.
- 성공 순간: 편지를 찾는 과정을 함께 즐기고 추억으로 남긴다.

## 5. 제품 원칙

1. 안전한 무작위성: 활성 공원과 공원 내 도착 좌표를 무작위로 정하되, 차도·수변 위험 구역·출입 제한 구역은 무작위 후보에서 제외한다.
2. 느린 소통: 실시간 채팅과 공개 반응을 배제하고 기다림을 경험의 일부로 만든다.
3. 최소한의 익명성: 실명은 수집하지 않되 신고·제재를 위한 내부 식별은 유지한다.
4. 현장 우선: 보상 없이도 현장에서 발견하는 경험 자체가 재미있어야 한다.
5. 최소 위치정보: 현재 위치는 찾기·획득 시점에만 사용하고 원본 좌표를 저장하지 않는다.
6. 실패 없는 체험: 권한 거부, GPS 오차, 편지 선점 상황에서도 사용자가 다음 행동을 알 수 있게 한다.

## 6. 핵심 경험

### 6.1 편지 띄우기

1. 사용자가 주제 또는 감정 태그를 고른다.
2. 최대 500자의 편지를 작성한다.
3. 익명 공개와 금지 콘텐츠 안내에 동의한다.
4. 자동 검수를 통과하면 병이 한강에 놓이는 연출이 시작된다.
5. 편지는 1~6시간 동안 표류한 뒤 한강공원에 도착한다.

보내기는 한강 현장에 있지 않아도 가능하게 한다. 발신 위치를 시작점으로 쓰지 않아 개인정보 노출을 막고 공급 부족을 줄인다.

### 6.2 편지 찾기

1. 사용자가 “주변 편지 찾기”를 선택한다.
2. 위치 사용 목적을 확인한 뒤 권한을 요청한다.
3. 지도에는 “○○한강공원에 편지 N개가 떠내려왔어요”만 보여준다.
4. 사용자는 정확한 좌표·거리·방향 안내 없이 공원 안을 직접 탐색한다.
5. 찾기 모드에서 숨은 목표 좌표 40m 이내에 들어오면 카메라 화면 또는 촬영 이미지 위에 병이 나타난다.
6. 사용자가 병을 터치하면 서버가 위치와 선점 여부를 최종 검증한다.
7. 검증에 성공한 한 사람에게만 편지 본문을 공개한다.

### 6.3 편지 읽기

- 편지를 획득한 한 명만 본문을 읽는다.
- MVP에서는 답장, 댓글, 채팅을 제공하지 않는다.
- 신고된 편지는 즉시 숨기고 검토 결과에 따라 삭제·제재한다.

고도화 단계에서는 편지를 실제로 획득한 사용자에게만 “익명 대화 요청” 권한을 부여할 수 있다. 발신자가 수락해야 채팅이 열리고, 어느 한쪽이 종료하거나 차단하면 다시 열 수 없는 구조를 우선 검토한다.

## 7. 편지 생애주기

| 단계 | 사용자에게 보이는 표현 | 기본 규칙 |
|---|---|---|
| 검수 중 | 물결에 띄울 준비를 하고 있어요 | 자동 검수 최대 10초 목표 |
| 표류 중 | 한강을 따라 흐르고 있어요 | 1~6시간 |
| 도착 | ○○한강공원에 도착했어요 | 공원명과 재고만 공개, 현장 획득 가능 24시간 |
| 재표류 | 아직 주인을 만나지 못해 다른 공원으로 떠나요 | 24시간 미획득 시 이전과 다른 무작위 공원 재선정 |
| 획득 | 누군가 편지를 발견했어요 | 한 명만 획득 |
| 만료 | 편지는 다시 한강으로 돌아갔어요 | 최대 3개 공원·72시간 뒤 |
| 차단 | 운영 정책에 따라 편지를 보낼 수 없어요 | 검수·신고 결과 |

- 텍스트 편지 작성·자동 검수·띄우기
- 가상 표류 애니메이션과 상태 표시
- 사전 등록 공원·안전 탐색 영역·제외 영역 관리

- 카메라 기반 AR풍 병 발견 연출과 폴백

- 친구 지정 발송
- 편지 검색, 인기 순위, 사용자 프로필
- 현금성·포인트 보상

- 유료 아이템과 광고

## 9. 운영 권역과 안전 지점

### 9.1 초기 권역

여의도, 반포, 뚝섬, 망원, 잠실 한강공원을 우선 후보로 삼는다. 각 공원에 사람이 접근 가능한 “안전 탐색 영역”을 다각형으로 등록하고, 도착 좌표는 활성 영역 안에서 무작위로 생성한다. 실제 오픈 전 현장 답사로 영역과 제외 구역을 확정한다.

### 9.2 지점 선정 기준

- 공공 보행로에서 접근 가능
- 야간에도 최소 조명 확보
- 차도, 자전거 전용도로, 계단, 급경사, 수변 난간 바깥과 충분히 이격
- 공사·행사·침수 시 원격 비활성화 가능
- 장애물 없이 GPS 정확도가 비교적 안정적
- 머무르더라도 통행을 방해하지 않는 공간
- 운영 시간 또는 접근 제한을 데이터로 관리 가능

무작위 좌표 생성 시 안전 탐색 영역 안에서 후보점을 뽑고, 위험 시설·수변·차도·자전거도로·공사 구역 등의 제외 영역 및 최소 이격거리를 통과한 좌표만 확정한다. 따라서 사용자에게는 무작위로 보이지만 운영상 접근 불가능한 좌표는 생성되지 않는다.

### 9.3 날씨·안전 운영

- 호우·홍수·폭염·한파·대형 행사 시 권역 또는 지점을 일괄 중지한다.
- 중지된 지점의 편지는 안전한 다른 지점으로 재배치한다.
- 사용자가 이동 중 화면을 오래 보지 않도록 “멈춘 뒤 확인해 주세요” 안내를 노출한다.
- 밤 시간에는 강변 가까운 지점을 제외하거나 획득 반경을 넓힌다.

## 10. 콘텐츠 안전 정책

### 10.1 허용 방향

- 일상 이야기, 위로, 응원, 질문, 감사, 짧은 고민
- 불특정 성인을 대상으로 한 비상업적이고 비공격적인 내용

### 10.2 금지 내용

- 전화번호, 이메일, SNS 계정, 주소 등 직접 연락·식별 정보
- 만남 또는 거래를 구체적으로 유도하는 내용
- 혐오, 괴롭힘, 협박, 성적 착취, 불법 행위, 사기, 광고
- 자해·타해를 조장하거나 구체적 방법을 제공하는 내용
- URL, 결제 요청, 쿠폰·홍보성 문구

### 10.3 검수 체계

1. 입력 중 연락처·URL·금칙어를 즉시 감지한다.
2. 제출 시 자동 분류기로 위험도를 판정한다.
3. 고위험은 거절, 중간 위험은 보류 후 사람 검수, 저위험은 발송한다.
4. 수신자가 신고하면 즉시 숨기고 운영자가 검토한다.
5. 반복 위반 사용자는 단계적으로 발송 제한 또는 영구 차단한다.

## 11. 공급 균형 설계

편지 수보다 수집자가 많으면 빈 방문이 생기고, 수집자보다 편지가 많으면 발신자가 결과를 받지 못한다. 따라서 공원별 재고와 예상 방문량을 함께 운영한다.

- 공원별 노출 수량 상한을 둔다.
- 한 사용자의 발송은 하루 3통, 동시에 표류 가능한 편지는 2통으로 제한한다.
- 같은 사용자의 연속 획득은 하루 5통으로 제한한다.
- 공원별 편지 개수만 공개하고 정확한 좌표, 거리, 방향은 공개하지 않는다.
- 도착 편지가 없을 때는 “헛걸음”을 유도하지 않고 다른 공원 또는 다음 도착 예상 시간을 안내한다.

## 12. 수익 모델

MVP는 리텐션과 현장 전환을 검증하기 위해 무료로 운영한다. 이후에도 편지의 도달 우선권이나 다량 발송을 판매하면 스팸과 불공정성이 생기므로 지양한다.

후속 후보는 다음과 같다.

- 병 모양, 편지지, 봉인 스티커 등 꾸미기 아이템
- 계절·공원 테마 컬렉션
- 공식 문화행사와 연계한 한정 편지지

디지털 아이템 판매 시 앱인토스 인앱결제 정책과 환불·상품 지급 기준을 별도 설계한다.

## 13. 핵심 지표

### 13.1 북극성 지표

주간 “안전하게 전달 완료된 편지 수”: 자동 검수를 통과하고, 현장에서 획득되어 신고 없이 읽힌 편지 수.

### 13.2 퍼널 지표

| 단계 | 지표 | MVP 목표 초안 |
|---|---|---|
| 유입 | 온보딩 완료율 | 70% 이상 |
| 보내기 | 작성 시작→발송 완료율 | 60% 이상 |
| 찾기 | 공원 조회→현장 반경 진입률 | 20% 이상 |
| 획득 | 반경 진입→획득 성공률 | 70% 이상 |
| 전달 | 도착 후 72시간 내 획득률 | 50% 이상 |
| 몰입 | 공원 진입→탐색 모드 실행률 | 60% 이상 |
| 리텐션 | 7일 내 재방문율 | 20% 이상 |
| 안전 | 편지 1,000통당 신고 수 | 10건 이하 |
| 품질 | 신고 후 24시간 내 처리율 | 95% 이상 |

목표값은 클로즈드 베타 데이터가 없는 상태의 가설이며, 2주 단위로 재설정한다.

## 14. 출시 전략

### 14.1 단계

1. 내부 알파: 가상 위치와 테스트 지점으로 전체 상태 전이 검증
2. 현장 알파: 운영팀이 2개 공원에서 GPS·카메라·안전성 검증
3. 초대 베타: 5개 공원, 일일 편지 상한을 둔 제한 운영
4. 공개 MVP: 지표와 신고 운영이 기준을 충족하면 앱인토스 공개
5. 확장: 공원·테마·알림·꾸미기 기능을 순차 추가

### 14.2 앱인토스 적합성

비게임 미니앱으로 설계하며, 주요 기능은 토스 안에서 완결한다. 권한은 앱 진입 즉시 요청하지 않고 사용 맥락에서 목적을 설명한 뒤 요청한다. 권한 거부 시에도 편지 작성과 활동함은 이용할 수 있게 한다. 앱인토스 공식 가이드상 비게임 미니앱은 공통 내비게이션, 라이트 모드, 권한 거부 폴백, 불법·선정 콘텐츠 차단 등 검수 항목을 충족해야 한다.

## 15. 주요 위험과 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| 불쾌한 익명 콘텐츠 | 사용자 신뢰와 출시 심사 저하 | 사전 자동 검수, 신고 즉시 숨김, 반복 위반 제재 |
| 현장 안전사고 | 인적 피해와 서비스 중단 | 안전·제외 영역, 현장 답사, 날씨·행사 원격 중지 |
| 편지 재고 부족 | 헛걸음과 이탈 | 출발 전 재고 표시, 권역별 상한·재배치, 파일럿 제한 |
| GPS 오차·조작 | 획득 실패 또는 부정 획득 | 정확도 조건, 서버 판정, 속도·반복 패턴 탐지 |
| 실시간 AR 미지원 | 핵심 연출 약화 | 촬영 이미지 오버레이 폴백을 P0로 확보 |
| 위치정보 규제 미준수 | 출시 지연·법적 리스크 | 신고·약관·동의·보유 정책 사전 법률 검토 |
| 앱인토스 정책 변동 | 재개발·반려 | 최신 SDK 2.x와 검수 체크리스트를 릴리스마다 재확인 |

## 16. 로드맵

### P0 — MVP

텍스트 편지, 5개 공원, 안전 탐색 영역 내 무작위 좌표, 표류·재표류, 위치 획득, AR풍 연출, 신고·운영 도구.

### P1 — 경험 개선

선택형 알림, 편지 도착 예상 시간, 공원 혼잡도, 계절 테마, 접근성 개선.

### P2 — 확장

편지 획득자 한정 익명 채팅, 꾸미기 아이템, 공식 행사 협업, 다른 수변 공원 확장, 고급 AR 및 공간 인식. 공개 피드와 획득자 외 사용자와의 대화는 제품 원칙에 맞지 않으므로 제외한다.

## 17. 의사결정이 필요한 항목

- 실제 서비스명과 상표·도메인 사용 가능 여부
- 최초 5개 공원과 공원별 안전 탐색·제외 영역
- 편지 최대 글자 수 300자 또는 500자
- 도착 시간 범위 1~6시간 또는 3~12시간
- 야간 운영 시간과 지점별 접근 가능 시간
- 카메라 실시간 미리보기 성공 시 AR풍 연출의 수준
- 자동 콘텐츠 검수 공급사와 사람 검수 운영시간
